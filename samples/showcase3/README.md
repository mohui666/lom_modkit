# 全节点样例 3.0

当前样例包含 10 章、205 个流程节点，覆盖全部 71 类节点。用于查看编辑方式，以及生成游戏手动验收包。第一章使用“修改人物称号”为赵活设置“唐门新秀”。

## 打开与生成

可在编辑器中打开本目录。需要重新生成时，在仓库根目录执行，输出目录应尚未存在：

```sh
cargo run --locked -p lomc --example build_showcase3 -- out/showcase3-check
cargo run --locked -p lomc -- inspect out/showcase3-check/showcase3.lommod --json
```

- `source.json`：维护样例时修改的源文件。
- `manifest.json`、`story/`：可直接由编辑器打开的工程。
- `assets/`：样例自有素材。
- `out/showcase3-check/`：上述命令生成的工程和作品包，不提交到 Git。

生成器位于 [build_showcase3.rs](../../rust/lomc/examples/build_showcase3.rs)，会检查节点覆盖。省略输出参数可刷新本目录的工程 JSON，完成后检查 diff。

## 内容

样例包含人物登场、换表情、气泡、同时执行组、背景与书页、音效特效、选项与检定、事件任务、自定义物品、决斗和战役等。原版剧情导入示例使用自编原文；实际原版资源从玩家自己的游戏读取。

主路径包括演出、Gameplay、可跳过的 Combat／Battle，以及死亡测试或安全返回。事件演出、原版剧情补丁和人物补绘等章节可单独选择查看。

## 游戏手动检查

1. 退出游戏，在编辑器同步 Host 后导出或试玩。
2. 检查图片、人物、音频、气泡及同时执行动作。
3. 检查选项汇合、任务状态、结算和跨章流程。
4. 若选择 Combat／Battle，检查人物、数值、胜负返回和死亡流程。
5. 确认结束时正确返回游戏，没有残留演出。

生成和离线检查通过不代表全部游戏路径已经实测。完整验证入口见 [测试矩阵](../../docs/chs/test_matrix.md)，功能边界见 [当前能力](../../docs/chs/current_capabilities.md)。

第一章还展示了无立绘画外音（默认“？？？”与自定义姓名），以及临时高亮和恢复对白自动压暗；这些新选项需要 Host 1.5.1。

第一章的人物旋转演示 0° → +355° → +360°，保留大圈和剩余 5°；需要 Host 1.5.2。
