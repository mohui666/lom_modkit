# 自由模式剧情与人物立绘

## 指定时间和地点进入剧情

在“文件 → 从模板新建”选择“自由模式剧情”。模板包含开场与练功场事件两章：开场结束后进入自由模式；四月上旬点击练功场（`Center`）时进入事件，结束后继续养成。当前游戏的新战役从四月上旬开始，模板与此初始时间一致。若该地点有待播放的原版主线或支线，会先播放原版剧情；新战役的练功场教学就是这种情况。

在“编辑 → 作品设置”的自由模式触发器中修改地点、月份、旬和目标章节，也可以设置好感度及剧情旗标条件。条件同时满足才触发，多行按顺序匹配。当前时间条件为月份和旬，没有年份字段。

模板使用独立的剧情旗标记录事件完成，事件中的 `flag` 节点将其写入游戏经历；触发器的 `when_flag_clear` 使用同一个标识。因此完成后的剧情不会重复触发。每个新项目生成不同的战役与旗标身份。

保留 `campaign.new_game=true` 的 v3 隔离存档规则。“禁用原版事件”默认关闭，其他时间继续原版养成；官方主线、支线仍优先于地点默认活动。事件的最后一步应为“结束剧情”，留空“下一章节”即可返回自由模式。

## 人物预览与中文选择

右侧“人物立绘”页显示当前人物图片。切换人物、表情或赵活外观会更新预览；图像保持比例，使用本地素材库。素材设置见 [Mac 编辑器](macos.md#立绘素材)，Windows 也使用同一目录选择入口。

提取器按 Addressables catalog 的内部资源地址选取 Sprite；同一资源包中不同人物或外观的 `normal` 等同名图片不会混用。旧版提取缓存需要用修正后的工具生成到新目录，再从编辑器选择该目录，才能刷新内存中的图片。

在人物下拉列表中按名称搜索并选择，保存时写入对应资源 ID；搜索文字不会成为字段值。同名但 ID 不同的资源显示稳定数字以便区分，不改变台词和保存的数据。高级引用允许手填 ID，未知资源仍由校验器报告。

## 照镜子后的赵活

在“人物登场”步骤中选择赵活，再设置“赵活外观”。可选值为“随游戏天赋”“普通赵活”“美颜赵活”。

保存的角色 ID 为 `player`，外观单独保存在 `appearance`：

```json
{"id":"show1","type":"show","character":"player","position":"M","portrait":"normal","appearance":"beautified"}
```

`appearance` 只允许用于 `player` 的 `show` 步骤，值为 `game`、`original` 或 `beautified`。后续对白沿用这次登场的外观；再次登场可以切回普通赵活。F5 的舞台前导也保留此选择。

Host 通过游戏 `CharacterPlaceholder` 的自恋主角配置加载立绘，表情仍使用 `normal` 等原有标识。该过程不修改天赋等级和官方配置资产。导出器要求 `min_host_version >= 1.1.2`，未填写时自动补入，已有更低版本声明时明确报错。

`samples/showcase3/` 第一章包含美颜赵活登场、对白和恢复原版的示例。以下是 Rust 迁移前的历史实机记录，不代表当前 Rust 工具端已完成实机验收。2026-10-02 在 Windows 游戏 `release_1.0.5000.13` 中使用独立测试战役验证：普通、美颜、恢复普通的外观切换正确；四月上旬的地点事件能够触发，时间和好感度不符的规则不会命中；结束后回到自由模式，存档重载后再次进入练功场恢复原版活动，没有重复播放事件。该历史轮次未对 Showcase 的全部 Combat/Battle 节点重新进行游戏验收；当前 Rust 迁移没有新增 Windows 或游戏实机测试。
