# Windows 快速开始 · 1.6.2

## 下载并打开

从发布页下载 `lom-editor.exe` 附件，双击即可使用。[1.6.2 下载页](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.2)。AI 创作所需的接口、skill、文档和示例可通过 `lom-editor.exe --cli sdk -o sdk --json` 导出。

运行只需要编辑器 exe；授权说明已内置到组件缓存。

| 文件或目录 | 用途 |
| --- | --- |
| `lom-editor.exe` | 编辑器 |


配套组件已内置在 exe，运行时自动准备到系统缓存，无需手动复制文件夹。

## 升级到本版

1. 可通过“检查更新 → 更新并重启”升级；也可保存作品、退出编辑器后手动替换新版 `lom-editor.exe`。
2. 使用新版编辑器打开自己的项目。
3. 退出游戏后启动新版编辑器，已安装的 Host 会自动同步。在“游戏与 MOD”核对编辑器与内置 Host 为 1.6.2；已配置过游戏时可点击“重新配置游戏环境”，再重启游戏。较新 Host 会被保留，旧 Host 不能降级覆盖它。后台视频使用当前编辑器内置的 Host。
4. 给原版人物追加图片时，从“素材管理 → 作品素材 → 为原版人物添加立绘…”导入；预览缺图时再从游戏预览素材中提取。

编辑器内的“检查更新 → 更新并重启”更新编辑器、编译器及随包的两个游戏接入文件。游戏目录中的接入组件通过上述第三步更新。

旧工程中的小梅 `girl5` 无需改为固定原版战斗或固定血量。若曾安装临时的小梅兼容补丁，先停用该补丁，再用新版 Host 试玩。

Windows 可只下载 `lom-editor.exe` 运行，提取器、音频解码器、Host、导出助手及加载器已内置。首次运行会自动准备到 `%LOCALAPPDATA%/lom_modkit/components`；不需要 exe 旁边的配套目录，也不需要 Python。

当前组件准备成功后，会自动清理同一缓存下其他版本／旧构建的组件目录，仅保留当前使用的目录。Windows 正在占用的旧组件暂时保留，下次启动再检查；链接目录和非组件目录不会清理。作品、设置和提取的素材不在此清理范围。

组件缺失或混用旧版本时，可在“检查更新”中选择“修复并重启”，重新安装当前版本的程序。安装使用已下载并校验的新助手，项目、素材和设置保留。旧程序无法完成更新时，手动下载新版 exe 后运行。

更新窗口显示总下载进度、已下载／总大小、平均速度、用时及各文件的下载／校验状态。连续 15 秒没有收到数据会显示提示，可继续等待或点“取消更新”，再到发布页面手动下载。全部文件下载并校验完成后才开始安装；取消不会安装已下载的文件。

默认用户内容库位于 `%APPDATA%\lom_modkit\repository`，设置位于 `%APPDATA%\lom_modkit\rust`。项目和素材保存在作者选择的目录中，升级后直接打开已有项目即可。

## 配置游戏

1. 退出游戏，打开“游戏与 MOD”。
2. 点击“一键定位游戏目录”，从找到的 Steam 安装中选择要使用的游戏。需要手动选择时，选中包含 `Mortal.exe` 和 `Mortal_Data` 的文件夹。
3. 确认目录后点击“一键配置游戏”，等待安装检查完成。
4. 配置就绪后，可使用“安装 / 更新当前作品”或“安装 .lommod 文件…”安装作品。当前作品已经安装时，会重新导出并更新原安装包，保留启用／停用状态。需要离线配置时，使用“高级维护 → 使用官方离线压缩包配置…”。

已安装 MOD 列表提供“删除 MOD”，仅删除所选安装包，保留项目与存档。新项目自动生成独立作品编号；导出检查所选目录及当前游戏中的编号冲突，遇到其他作品复用编号时，提示在“作品设置”修改。不同显示名和文件名不会绕过这项检查。

详细安装、修复和回滚操作见 [维护者手册](maintainers.md#windows-游戏接入与-runtime-回滚)。

## 提取预览素材

打开“素材管理 → 游戏预览素材”，点击“一键提取游戏资产”，选择自己的游戏安装目录。提取完成后自动载入立绘、背景、插图、书页和气泡动画。官方图片保存在本机素材缓存中。

已有素材库可使用「补充提取」，加入 28 张决斗专用背景的缩略图，包括后山挑战场；随后在决斗步骤中选择对应背景。使用专用背景的作品需要 Host 1.6.2，普通剧情场景背景继续兼容。

如果旧版提示组件缺失，下载新版 `lom-editor.exe` 后直接运行即可。新版会自动补齐缺失的组件缓存；若准备失败，请检查系统磁盘空间和写入权限。

## 创建、保存和试玩

- “文件 → 新建项目 → 新建原版附加剧情”用于向原版流程增加事件，“新建自由剧本”用于自己的开场和独立存档。
- 左侧添加步骤，中间填写内容，右侧查看预览。图片和人物素材从“素材管理 → 作品素材”导入。
- 菜单下方的标签栏可打开多个工程，关闭编辑器后恢复已保存工程的标签及编辑位置。选中步骤后可跨标签或不同编辑器窗口复制粘贴；引用的作品素材及其他章节需另行导入。打开作品的外层目录时，编辑器会识别直属工程和 `.lommod`，有多个候选时让你选择。
- 预览工具栏可选择分辨率或输入自定义宽高，保存在个人设置中并在重启后恢复；不会修改作品。舞台锚点不一定是图片中可见的脚底，调整位置前先检查实际图片。
- 在“画面预览”先勾选“调整画面”，再拖动人物或自定义插图的主体改位置，拉四角等比缩放。“复位”恢复默认布局，`Esc` 取消当前拖动；素材默认大小保持原值，新增布局需要 Host 1.4.4。
- 按 `Ctrl+S` 保存作品，按 `F6` 检查章节，再到“发布 → 发布体检与打包”检查整部作品。
- “导出 Mod”生成作品包。顶栏“试玩”或 `F5` 安装临时试玩包并进入游戏，右侧“播放”展示编辑器预览。
- 顶栏“生成视频”按原生自动播放节奏输出 MP4，可预设剧情选项，默认在后台独立游戏进程中生成。输出分辨率与编辑器预览分开设置；不支持自动操作的战斗或交互面板会提示停止。普通试玩和成片均不叠加可见或隐藏水印。
- 检查原版章节前后的衔接时，使用 [CLI 的原版前置事件试玩](cli_parameters.md#原版前置章节与事件衔接试玩)；单章 F5 和编辑器预览不执行前一段原版剧情。
- 导出提示缺少存档身份时，点击“去填写存档身份”。使用小写英文字母、数字、下划线或短横线填写编号。已发布作品沿用原编号以关联玩家存档。

按 `F1` 打开帮助。完整流程见 [软件使用](software_usage.md)。

## 游戏内 F8 工坊

升级 Host 并重启游戏后，在养成界面默认按 `F8` 打开「MOD 工坊」。右上角可以独立选择工具语言，不影响游戏或作品对白。进入「开发测试」可浏览原版事件、前后任务、日期与触发条件；普通「原版＋MOD」进度启用开发测试后可按日期或原版章节开头跳转。隔离事件测试还需勾选「同时运行原版事件」与「启用游戏内开发者跳转」。

准备参数不会立即跳转，执行跳转也不会重建此前的选择和剧情历史。完整操作见 [F8 工坊与开发工具](software_usage.md#游戏内-mod-工坊与开发工具)。

## 本版功能与验证范围

原版整章结构化编辑、路线连线、四语界面和旧格式导入见 [软件使用](software_usage.md)。本版变化见 [1.6.2 Release](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.2)，验证范围见 [测试入口](test_matrix.md)。路线图从“文件 → 原版剧情 → 原版路线图…”打开，游戏中按 `Ctrl+F6` 标记后，可用“打开最近游戏标记”定位。

编辑器二维预览、离线模拟、原生视频和实际游戏试玩分别覆盖不同范围，不能用模拟通过代替画面检查。功能限制见 [当前能力](current_capabilities.md)。

第三方组件的许可随包提供，项目许可位于 `LICENSE`，来源和致谢位于 `THIRD_PARTY_NOTICES.md`。

Windows 发布附件只提供编辑器 exe。Skill、Python 接口、文档和示例保留在 exe 导出的 SDK 中。
