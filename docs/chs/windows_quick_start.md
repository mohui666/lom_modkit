# Windows 快速开始 · 1.4.12

## 下载并打开

从发布页下载 `lom_modkit-v1.4.12_windows_x64.zip`，完整解压后进入 `lom_modkit` 文件夹，双击 `lom-editor.exe`。[1.4.12 下载页](https://github.com/mohui666/lom_modkit/releases/tag/v1.4.12)

编辑器运行目录包含以下内容。

| 文件或目录 | 用途 |
| --- | --- |
| `lom-editor.exe` | 编辑器 |
| `lomc.exe` | 编译器与更新助手 |
| `runtime` | 随包游戏接入组件 |
| `assets` | 加载器等工具资源 |
| `asset-extractor` | 本机游戏预览素材提取组件 |

请从完整文件夹内运行编辑器。首次安装直接下载完整压缩包，可同时获得以上组件。

## 升级到本版

1. 保存作品，退出编辑器，完整解压本版压缩包。
2. 使用新文件夹中的编辑器打开自己的项目。
3. 退出游戏后启动新版编辑器，已安装的 Host 会自动同步。在“游戏与 MOD”核对编辑器、随包 Host 和游戏已安装 Host 均为 1.4.12，必要时点击“更新游戏 Host”。
4. 给原版人物追加图片时，从“素材管理 → 作品素材 → 为原版人物添加立绘…”导入；预览缺图时再从游戏预览素材中提取。

从 1.4.8 及更早版本升级时，原版章节与路线读取需要完整包中的新版素材提取组件。编辑器内的“检查更新 → 更新并重启”更新编辑器、编译器及随包的两个游戏接入文件，已有完整 1.4.9 安装可使用内置更新。游戏目录中的接入组件通过上述第三步更新。

从 1.4.8 起，覆盖更新造成更新组件缺失或混用旧版本时，可在“检查更新”中选择“修复并重启”，重新安装当前版本的四个程序文件。安装使用已下载并校验的新助手，项目、素材和设置保留。已经被旧版完整包检查挡住的用户，需先换上修复版主程序，再检查更新；旧程序本身的检查不会随服务端发布而改变。

默认用户内容库位于 `%APPDATA%\lom_modkit\repository`，设置位于 `%APPDATA%\lom_modkit\rust`。项目和素材保存在作者选择的目录中，升级后直接打开已有项目即可。

## 配置游戏

1. 退出游戏，打开“游戏与 MOD”。
2. 点击“一键定位游戏目录”，从找到的 Steam 安装中选择要使用的游戏。需要手动选择时，选中包含 `Mortal.exe` 和 `Mortal_Data` 的文件夹。
3. 确认目录后点击“一键配置游戏”，等待安装检查完成。
4. 配置就绪后，可使用“安装当前作品”或“安装 .lommod 文件…”安装作品。需要离线配置时，使用“高级维护 → 使用官方离线压缩包配置…”。

详细安装、修复和回滚操作见 [维护者手册](maintainers.md#windows-游戏接入与-runtime-回滚)。

## 提取预览素材

打开“素材管理 → 游戏预览素材”，点击“一键提取游戏资产”，选择自己的游戏安装目录。提取完成后自动载入立绘、背景、插图、书页和气泡动画。官方图片保存在本机素材缓存中。

如果提示缺少素材提取组件，请检查编辑器旁是否有完整的 `asset-extractor` 文件夹，并使用本版完整压缩包重新解压。发布页的单独程序文件供已有完整安装更新使用。

## 创建、保存和试玩

- “文件 → 新建原版附加剧情”用于向原版流程增加事件，“新建自由剧本”用于自己的开场和独立存档。
- 左侧添加步骤，中间填写内容，右侧查看预览。图片和人物素材从“素材管理 → 作品素材”导入。
- 在“画面预览”先勾选“调整画面”，再拖动人物或自定义插图的主体改位置，拉四角等比缩放。“复位”恢复默认布局，`Esc` 取消当前拖动；素材默认大小保持原值，新增布局需要 Host 1.4.4。
- 按 `Ctrl+S` 保存作品，按 `F6` 检查章节，再到“发布 → 发布体检与打包”检查整部作品。
- “导出 Mod”生成作品包。顶栏“试玩”或 `F5` 安装临时试玩包并进入游戏，右侧“播放”展示编辑器预览。
- 导出提示缺少存档身份时，点击“去填写存档身份”。使用小写英文字母、数字、下划线或短横线填写编号。已发布作品沿用原编号以关联玩家存档。

按 `F1` 打开帮助。完整流程见 [软件使用](software_usage.md) 和 [核心功能教程](core_tutorial.md)。

## 本版功能与验证范围

原版整章结构化编辑、路线连线、四语界面和旧格式导入见 [更新说明](../../RELEASE_NOTES_v1.4.12.md)。路线图从“文件 → 原版路线图…”打开，游戏中按 `Ctrl+F6` 标记后，可用“打开最近游戏标记”定位。

本版游戏验证覆盖原版章节独立入口、选择分支、人物清除、动态去向及旧格式样例的资源、扩展接口和热重载恢复。完整范围见 [当前能力](current_capabilities.md#1411-验证范围)。
