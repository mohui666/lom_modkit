# 1.4 开发说明

开发分支：`codex/v1.4-custom-content-saves`。程序与公开发布版本均为 `v1.4.0`，功能仍处于公开测试阶段。为支持现有用户检测并更新，使用普通最新版 Release；发布页、更新说明和包内日志明确标注测试状态，见[更新日志](../../RELEASE_NOTES_v1.4.0.md)。

## 选择玩法

标题页只保留一个「开始游戏」，进入后选择下面三种玩法。选择「纯 MOD」后再进入具体作品列表：

| 入口 | 游戏内容 | 存档与界面 |
| --- | --- | --- |
| 纯原版 | 原版流程，不触发已安装的 MOD 剧情 | 原版存读档界面和原版栏位 |
| 原版＋MOD | 原版主线与已安装的附加剧情作品 | 独立的附加 MOD 存档界面和 `mod_addon_default` 栏位 |
| 纯 MOD | 先从作品列表选择一部独立剧本，再开始或继续 | 仅显示该作品的介绍和独立存档 |

从游戏菜单的「读取游戏」进入时，直接打开当前玩法的存档页。纯 MOD 会直接显示正在进行的作品，不必重新选择；战役暂停菜单的读取入口也使用相同归属规则。返回标题后，原版继续／读档入口仍对应原版进度。

MOD 存档页保留游戏外框，使用咖啡伴侣的左侧存档列表、右侧心上人立绘与详情布局，支持手动／自动分类、按时间或栏位排序和备注。每个模式或独立剧本保留 20 个手动栏位和剧情／自由／战役三个自动栏位；覆盖和删除需要明确确认。空档不会显示为可读取的进度。

附加 MOD 的手动第一栏为 `mod_addon_default`，其余追加 `_s002` 到 `_s020`；三个自动栏追加 `_auto`、`_auto_free`、`_auto_battle`。纯 MOD 沿用既有 `mod_campaign_<campaign_id>` 存档名，不迁移或覆盖已有原版档。备注和宿主变量不写入原版 GameSave 格式。

附加 MOD 存档会同时记录所需的作品。卸载或禁用其中某个 MOD 后，存档保留，但读取时会列出缺失的 MOD 并停止，避免未知物品、功法或剧情在再次保存时丢失；重新装回相同 ID 的作品后可继续读取。没有依赖记录时会明确提示无法确认，不会默认为安全。纯 MOD 的独立进度同样不会因卸载作品被删除，需重新安装对应作品后读取。

存档界面源码移植自 [kevinnie2003／咖啡伴侣 v3.4.0 的 SaveBrowser.cs](https://github.com/kevinnie2003/LOMAssistant/blob/v3.4.0/LOMAssistant.Features.Extras/SaveBrowser.cs)，保留来源说明。布局、原生按钮、头像与字体模板沿用该实现；栏位归属、读写动作和备注接入 Host 的隔离规则，不需要安装 `LOMAssistant.dll`。详情使用 Host 能确认的实际存档信息，没有移植咖啡伴侣的整个剧情分析模块，也不随包分发其插件或截图。

## 创建自定义内容

编辑器素材库可新建「物品」「消耗品」「功法」「决斗援助」「自创招式」，仍可作为共享内容导入和导出。内容属于所在作品，通过 `user:命名空间.名称` 引用；不同作品中的同名内容不会共用背包记录、援助或招式状态。

- 物品：杂物或贵重品，配置图标、名称、说明和价格；通过物品步骤、事件奖励、商店和物品检定使用。
- 功法：独立书籍，配置修炼等级、每级所需点数、属性门槛与升级加成；通过书籍类别发放，在游戏原有修炼流程学习。
- 决斗援助：在决斗步骤的我方／敌方援助列表中选择。可按回合开始、行动结束或受击触发，配置概率、次数以及伤害、治疗、恢复气力效果。

- 消耗品：配置剧情／养成的属性变化，或决斗中的回血、回气。背包中选中道具后主动使用；决斗有独立道具入口，使用占用本回合行动并保留原版休息回气规则。数量随隔离存档保存，跨场景、暂停或无数量时不能使用。剧情可通过「使用消耗品」步骤主动消耗。
- 自创招式：配置攻击／暗器／绝招类型、基础威力、基础耗气、命中率、冷却、敌方使用概率及命中后的效果，在决斗节点中为双方分别装备。沿用原版克制、招架和伤害换算，基础耗气也可能受原版互拼规则影响。
- 招式动画：导入 1～120 张 PNG，在编辑器中追加、排序、移除和播放预览；配置帧率、命中帧及大小。指定帧实际触发伤害，结束后恢复原角色显示。不填动画时使用原版动作演出。

消耗品通过物品、奖励或事件结果获得；原版商店页仍只展示书籍、杂物和贵重品，因此自定义商店明确拒绝消耗品。自创招式的命中附加效果为伤害、回血和回气，无需编写 Lua 插件。样例已覆盖 67 类节点，并实际使用两类消耗品与四帧自创招式。

完整字段与示例见[用户内容](user_content.md)，可运行样例在 `samples/showcase3`。包含新玩法定义的作品要求 Host 1.4.0；旧作品的作者自述测试版本不会自动改写，新导出时需检查与最低 Host 版本的关系。

## 本地使用

本地 Windows 包位于 `out/v1.4/lom_modkit/lom-editor.exe`。游戏内需要安装随包的 Host；编辑器版本与游戏目录中的 Host 是两个独立目标。v1.4.0 设为最新版后，1.3.x 用户可检测更新；更新不会自动替换游戏目录中的 Host。
