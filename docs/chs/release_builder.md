# Release Builder

“文件 → 构建发布包…”是一条只在本机执行的发布流水线：

1. 校验最终 Manifest、SemVer 和 schema 版本；
2. 执行完整 Editing 体检，再套用 Release 严格规则；
3. 在输出目录的临时目录中编译并打包；
4. 对最终整包计算 SHA-256；
5. 同时生成 `<包名>.lommod.sha256`，并显示文件、大小、剧情/节点数和提醒摘要。

Release 错误会在任何产物生成前阻断。Warning 会保留在摘要中，但不会被一律升级成错误。实际包先在临时路径构建，编译失败不会留下半个 `.lommod`。

发布构建器不会安装 Mod、启动游戏、调用 Git、push、上传或发布网络 Release。普通“导出 Mod”仍保留原来的导出/可选自动安装体验；需要可分发产物时应使用“构建发布包…”。`.sha256` 是完整文件校验值，用来确认传输后的字节一致，不是作者签名或官方认证。
