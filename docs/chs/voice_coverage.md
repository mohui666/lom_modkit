# 语音覆盖

“运行 → 语音覆盖…”按三个层级统计 `say` 节点：

- 项目总计；
- 每个 Story；
- 每个人物。

每行显示已配音、未配音和覆盖率。`voice` 是非空字符串即计为已配音；发布前体检和打包器仍负责验证引用是否合法、内容是否存在，覆盖统计不会把“填写了错误引用”误称为资源有效。

`narrative` 与 `center` 对白统一归到“旁白”；角色对白与内心独白按 `character` 引用分组，缺失人物字段归到“未指定人物”。

窗口下半部列出全部未配音对白的 Story、节点、人物和文本。双击行或点击“定位未配音节点”会关闭统计窗口、切换到对应 Story 并选中节点，方便连续补录。统计只读，不自动写入或生成语音。
