# 原版特效与音效常用组合

先按场景找一行，再把这一行的「屏幕特效」和「音效」放进同一个「同时执行多个动作」。下表来自当前安装游戏的原版剧情：特效播放与音效调用直接相邻，中间没有对白、等待或分支。用途是便于挑选的归类，同一个特效也可以换声音使用。

特效名和音效名可以直接在编辑器中搜索。音效类型均选择「普通音效」；名称保留游戏原来的繁体字，例如搜索「砍人」「子彈」「格檔」。

## 照着设置一次：打中后震动并冒气泡

1. 先添加「人物登场」，让被打的人出现在画面上。
2. 添加「同时执行多个动作」。
3. 组内添加「屏幕特效」，选 `Hit_001`，用画面预览把位置移到被打处。
4. 再添加「音效」，类型选「普通音效」，选 `揍人_001`。
5. 再添加「人物震动」，选被打的人，时长可先试 **0.5 秒**。
6. 再添加「表情气泡」，选同一个人，选择想要的气泡样式；「动作后停留」可先试 **0.5 秒**。
7. 按 **F5** 查看整组配合。上面的 0.5 秒是方便起步的设置，可以按剧情节奏调整。

只要特效和声音时，保留前两项动作即可。要改变被打者的立绘表情，在整组前加「人物换表情」；移动、位移本身沿用这个人物的当前表情，不需要重新登场。

组内各动作同时开始，整组等最慢的动作完成后继续。普通音效启动后就继续，不会自动等整段声音播完；想让画面停留更久，可在组内加「等待」或调整动作后的停留。循环特效需要设置「自动停止」，或在后续步骤停止，不能把「动作后停留」当作特效播放期限。

## 选择时容易混淆的地方

- 特效名称与音效名称分别选择，不能把特效名填进音效。例如 `Sword_Fight_001` 在这里是特效，搭配的声音是 `格檔_002`。
- 同一个特效可以表示不同结果：`Sword_001` 配 `砍人_001` 表示命中，配 `格檔_002` 表示交锋或被挡。先选想表达的结果，再选声音。
- 「屏幕特效」与「表情气泡」是两种动作：前者摆在画面中，后者跟随选定人物。气泡可以与同人物震动、移动、位移一起使用；人物压暗时仍会隐藏气泡。
- 随机音效每次试听可能有变化。尚不能试听的复杂声音可用 F5 在游戏中确认，不必因此重做项目。
