## 缺陷修复与原路径复测

| 缺陷 | 修复与实际结果 |
| --- | --- |
| Windows 异常退出后不出现恢复候选 | 原非 Unix 分支把所有 owner 判为活动；改为 Windows 进程状态和创建时间检查。实际完成未保存副本、仅终止测试进程、重启发现候选、恢复和原目录保存；另一个仍运行实例的恢复目录独立验证受保护 |
| 长路径素材使恢复副本只写出一部分 | 263 个 UTF-16 单元的恢复目标在 tempfile persist 报 `os error 3`，缺 `session.json`。两个写入入口改用 Windows 规范化父目录；新 exe 实际写出 7 章/21 个素材文件及正确来源，全部素材字节相符，再异常退出、发现候选、恢复替换人物/属性并保存原目录 |
| `Ctrl+,` 实际无效 | 本机真实事件只有 Comma release、没有对应 press；Windows 补充精确修饰键 release 路径，保留去重、焦点与模态保护。新 exe 按原快捷键实际打开设置；临时按键诊断代码已移除 |
| 默认对话模式姓名消失 | 清除 `mode` 后预览缺省值与编译器不一致；预览缺省改为 `character`。最终构建重新打开同一节点，仍省略 `mode`，林灯姓名和正文位置恢复；本地截图 112 为失败，113/114 为新 exe 复测 |
| 非赵活人物残留赵活外观、表单重复/拥挤 | 普通人物切换清除不适用 `appearance`，保留导入无效 JSON 供校验；choice 只显示一个跳转选择器，调整字段宽度。新 exe 武师和原 choice 页面复测通过 |
| 流程图及错误定位 | 修复分支分层、回边、箭头尺寸和中文选项标签；真实循环图与长图复测通过。编译诊断链接保留可靠节点 ID，点击 `main/say_left` 定位第 3 节点，缺失目标本身继续报错 |
| 素材列表及显示名称 | 增加行边界、类型对齐和选中状态；实际重开、选择、滚动可辨。舞台用户人物 ID 改为素材显示名，保存 ID 不变 |
| WAV 失败静默、播放子进程窗口 | 非零退出反馈一次错误，主动停止不误报，Windows 播放进程隐藏控制台；损坏文件、播放和停止原路径实测通过 |
| Windows 测试夹具与文案 | 修正仅 Unix 实现的符号链接 fixture，Windows 实际执行相关包回归；保存菜单在 Windows 显示 `Ctrl+S` |

两项恢复缺陷分开验证：写出文件不等于形成完整副本，完整副本也不等于已发现候选或成功恢复。恢复范围仍受快照周期和有效项目状态限制；无效 JSON、未完成输入及最近一个周期内的编辑不保证恢复，详见 [自动恢复](editor_recovery.md)。

## 受阻、未执行与剩余限制

- 鼠标修饰键多选复制粘贴、多节点模板内部映射受本轮自动化接口能力限制，未实际操作；跨章范围复制和单节点模板通过不能替代它们。
- 未确认可用 FFplay/FFmpeg 或外部水印语料。OGG 实际播放受阻，缺 FFplay 时的错误提示 UI 未执行；`ffmpeg_real_video_extraction`、`original_python_image_and_video_corpus` 两项 ignored 不计通过。两个 Unix 限定保存符号链接用例未编入 Windows，也不计本轮通过。
- 未穷尽深色、其他 DPI、全部节点/资源/无效草稿组合。普通保存仍保留的文件没有外部修改覆盖保护；本轮确认的是待删除文件和未拥有文件的删除保护。
- **游戏启动、F5、插件安装或更新、游戏存档和游戏实机均未执行。** 游戏程序集只作为 Host 编译引用。Mac 实测及 Release 发布也未执行；Windows 通用外壳不以 Liquid Glass 为验收要求。
