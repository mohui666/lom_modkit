# 项目统计

“运行 → 项目统计…”打开一张只读表格，不修改项目、不执行内容，也不构建复杂 dashboard。

当前口径：

- **剧情章节 / 节点**：当前内存项目中的 Story 与全部节点；
- **对白**：`say` 节点数；
- **选项**：`choice` 节点数，同时显示其 options 总数；
- **结尾**：会终止当前 Story 的 `end`、`death`、`goto_scene` 节点；
- **人物**：所有节点 `character` 字段中不同的非空引用；
- **图片**：不同 `user:` 图片引用和 `assets/...` 直接图片路径；
- **音频**：不同 BGM、音效与 `say.voice` 引用；
- **语音覆盖**：带非空 `voice` 的 `say` / 全部 `say`，同时显示未配音数；
- **不可达节点**：复用流程图和发布前体检的同一 Story CFG 分析，不另造流转规则；
- **未使用资产**：可访问原 `.lommod` 或 Story 项目 `assets/` 时，以包内/目录资产减去直接路径与 `user:` 内容引用；未保存项目显示“不可用”。

目录资产统计只枚举相对路径，不读取、解码或执行资产内容，单次最多枚举 10 万文件。导入包通过现有只读包检查器取得资产清单。统计数是作者整理项目的提示，不替代发布前体检与打包校验。
