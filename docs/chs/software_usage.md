# 软件使用

本文对应 1.5.10 原生编辑器。首次安装与升级步骤见 [Windows 快速开始](windows_quick_start.md)。点击顶栏「帮助」或按 `F1` 打开帮助文档窗口，默认显示「使用指南」。左侧选择主题，右侧阅读正文，也可搜索关键词或切换「步骤查询」。点击表单标题旁的「说明」可直接查看对应操作。字段见 [作品格式](mod_format.md)。
改决斗/战役实现前先读 [反编译接口](decompiled_api.md)。

## 基本流程

项目手动保存一次后，默认每 5 分钟自动写回，可在「设置 → 常规」关闭或调整间隔。新项目和刚载入的恢复副本需先手动保存；每 30 秒的本地恢复副本仍保留。自动保存成功会显示实际路径，失败会保留修改并提示。详见 [自动保存与恢复](editor_recovery.md)。

「文件」按新建项目、打开与最近项目、保存、原版剧情、导出与发布、预览素材分组；「导出诊断报告」移到「剧情工具」。新建、打开、另存和撤销／重做旁显示对应快捷键。文本输入框获得焦点时，撤销／重做优先处理该输入框，不触发整个项目的历史操作。

1. 从「文件 → 新建项目」选择「新建原版附加剧情」或「新建自由剧本」，也可打开已有项目。附加剧情进入原版流程，自由剧本有自己的开场及隔离存档。左侧章节下拉旁点「＋ → 新建章节…」或「复制当前章节…」，再填写章节名称并确认；内部 ID 自动生成。
2. 中间表单直接编辑步骤。人物、表情、模式等直接选择；「默认」「无语音」等选项表示不设置对应字段，不用先勾选启用。普通创作不需要修改内部标识。
3. 右侧查看画面预览、人物立绘或流程图。「播放」只在编辑器内演示。`F6` 做章节校验并显示当前章节编译结果；完整作品的 Manifest、事件／任务及发布信息检查在「发布 → 发布体检与打包」的「编辑体检／发布体检」。
4. 用 `⌘S`（Windows/Linux 为 `Ctrl+S`）保存整个项目；「导出 Mod」生成 `.lommod`。Windows 的顶栏「试玩」／`F5` 会安装隔离试玩包、发送请求并启动游戏；它不是右侧「播放」。只演示软件时不要点击。Mac 不提供游戏试玩。
5. 音频、图片、自定义角色从「素材管理 → 作品素材 → 导入素材…」导入，先选类型和文件，再确认名称，引用 ID 自动生成。

Windows 中，`F5` 从当前步骤试玩，`Ctrl+F5` 从当前章节的起始步骤试玩；「剧情工具」菜单也提供这两个入口。快捷键不会改变当前选中的步骤。游戏中的 F5 调试器默认关闭，按 `F10` 打开或隐藏；调试器按钮只操作调试窗口。

试玩和导出前发现错误时，弹窗直接列出具体原因、所属章节和步骤，可逐项跳转修改。「复制诊断信息」包含完整错误清单。

右侧预览播放到选项时会等待选择，选完自动沿对应分支继续，不必再次点击「播放」。原本暂停时点击选项仍保持暂停；手动选择左侧步骤会停止自动播放。

Host 1.5.3 的智能自动播放使用游戏原来的「自动」按钮，仅在 MOD 演出时生效。文字显示完成后，按有效字数 ÷ 8 计算阅读停留，标准速度至少 1.2 秒；富文本标签和空白不计字数。自定义语音或原生 Writer 语音仍在播放时会等待，结束后至少再留 0.3 秒。菜单、日志、选项以及关闭自动时暂停计时；手动点击和快进沿用游戏操作。自由场景／标题页的 MOD 菜单可选择「自动播放速度」慢／标准／快，保存为本机玩家设置；不写入作品。编辑器右侧预览仍是示意计时，不能代替游戏内节奏验收。

选中「表情气泡」步骤，或包含人物气泡的「同时执行组」时，可直接拖动右侧预览中的蓝色气泡框调整位置。组内调整只写回对应人物的气泡动作，不改变同组的震动、移动或其他气泡；位置随工程保存。

Windows 顶栏「导出游玩包」将作品、自有素材、Host 与加载组件合并为可分发 ZIP，玩家解压后双击安装。普通「导出 Mod」继续生成单个 `.lommod`。原版人物补绘和新增表情使用[作品素材的扩展入口](user_content.md#为原版人物增加表情)。

「设置 → 常规 → 界面缩放」默认按窗口大小自动适配，同时保留 Windows 系统 DPI；也可关闭自动适配，手动设置界面缩放。窗口可缩至 640×400 点，小屏无需保持原先的三栏总宽度。

简体界面统一显示官方资源的简体名称。音乐列表展示曲名，悬浮条目可查看编号，搜索支持简体关键词与原版编号。

章节旁「＋」可新建分组、重命名当前分组，或将当前章节移入已有分组及「未分组」。新建分组时当前章节会归入该组。下拉列表按组展开与折叠，组内保留章节名称。分组随作品保存，支持撤销／重做。

每个步骤表单顶部可填写「节点备注」。左侧小字优先显示备注，未填写时显示节点编号，例如 `transition2`，并保留人物、对白等概要。

左侧章节下拉框下方的「章节设置」是带边框的按钮。点击后可修改章节名称、入口步骤；右上角「删除章节…」删除当前章节及其步骤。删除前会显示章名和步骤数；若作品入口、其他章节或事件引用了它，先选择替代章节，确认时同步修改这些引用。删除可撤销／重做，素材保留；保存后重新打开，已删除章节不会再出现。作品至少保留一个章节，因此只有一章时删除按钮不可用。

作品名旁「作品设置…」管理名称、作者和运行模式，可在「作品玩法」转换事件模式，并在「开场入口」关联开场事件与入口章节。左侧「剧情内容」编写演出，「剧情安排」编辑事件；事件下方的「任务进度（可选）」记录跨事件状态。日期可选精确／每年日期、从日期起、截至日期或日期范围；重复事件勾选「可以重复发生」并选择间隔。时间、属性和物品也可直接放在章节步骤中，用于开场设置或剧情中途变化；跨事件状态和统一发奖放在事件条件／结果动作中。详见 [事件与任务配置](events_and_tasks.md)。

资源选择器会翻译官方资源名称；不同 ID 的同名条目显示为「名称 1」「名称 2」。编号在完整列表上计算，搜索不会临时重排编号，也不会改写 JSON、资源名称或引用。章节、分区和作品内容库的同名项也按此方式区分。

人物搜索词只是查找输入，点选结果才改变人物；按 `Esc` 或点击结果区域外会取消搜索，保留原选择。需要填写内部 ID 时展开「手动输入」，点「使用此值」明确提交。对话模式选「对话（默认）」后，JSON 不写 `mode`，舞台仍按普通对话显示人物名称；用户人物显示素材名称，不把 `user:` 引用当作姓名。

角色选择列表上方可点「仅显示已登场角色」筛选，再点一次恢复全部。名单按当前预览路线、本步骤开始前的舞台状态生成，已退场或已清场的人物不列入；人物登场节点仍显示全部角色。筛选只影响列表，不改写旧节点或当前选择，也不作为编译限制。

演出人物选择按「人物 → 外观 → 表情」填写。赵活、唐门主要人物和主要女角色等已按人物整理：例如选择「虞小梅」，再选「入魔」，最后从这个外观实际具有的表情中选择。切换外观时仍可用的表情会保留；不再可用的表情恢复为普通表情，避免引用其他外观的表情。叶云裳与叶云啾仍是不同人物；普通配角保持原列表。

外观分组只整理编辑操作，项目仍保存原版实际人物 ID，旧项目不自动改写。赵活的普通／美颜继续使用既有 Host 外观功能；其他造型使用各自的官方人物配置。不同配置在原版舞台上仍是独立对象，场中换装时先让旧外观退场，再让新外观登场。

人物目录也包含游戏用于演出的道具立绘。选择它们不代表创建了新角色；在「对话」模式下可以填写台词，但不会自动配音，语音需要另选。各节点允许的对象仍受自身字段规则限制。

展开表情列表后，可用 ↑／↓ 切换并同步右侧预览，列表保持打开；搜索框和手动输入框获得焦点时，按键交给输入框。音乐／音效步骤选择曲目后可点「试听音频」，点「停止试听」结束。原版音乐、普通音效与环境音从本机游戏按需读取，不启动游戏、不修改剧情。原版随机音效按实际播放分支选择声音，并保留对应音量和音高，每次试听可能不同；尚不支持的实时混音仍需进入游戏确认。音频读取器使用 Rust，原生解码器已内置在 Windows exe 中，随主程序更新。试听临时文件在停止、播放结束或关闭编辑器时清理。

从旧版升级时，下载新版 `lom-editor.exe` 后直接运行。组件首次运行自动释放到 `%LOCALAPPDATA%/lom_modkit/components/<版本及内容编号>`，丢失后重开会自动补齐。若仍无法准备组件，请检查系统磁盘空间和当前账户的写入权限，已有作品无需重建。

「人物震动」需要目标人物已登场，时长大于 0（默认 0.5 秒），游戏中震动完成后再执行下一步，避免紧接着换立绘或登场把震动覆盖。选择该步骤后点右侧「播放」，预览显示衰减震动，结束后恢复原位置；仅选中步骤时显示静态画面。编辑器的震动曲线用于示意，不保证逐帧复现官方 iTween 的随机结果。

素材编辑和离线测试的有效输入随项目保存；未完成输入会保留，保存或切换受阻时先修正，或点「撤销未完成的输入」。自动恢复的范围见 [自动恢复](editor_recovery.md)。批量修改与模板从「剧情工具」菜单进入；统计、配音覆盖与打包检查集中在「发布」。

## 页面与游戏配置

顶栏直接切换「剧情编辑」「素材管理」「游戏与 MOD」「发布」。剧情页保留章节、步骤表单与右侧预览；其他页面使用完整工作区，切回剧情时保留原章节与步骤选择。素材页分为作品素材、游戏预览素材和共享内容库。切页前检查未完成的素材输入；无效输入保留在原页面并提示修正。素材、游戏和发布页的 Delete／步骤复制粘贴快捷键不会修改隐藏的剧情步骤。

Windows 首次进入「游戏与 MOD」，先点「一键定位游戏目录」，读取 Steam 安装信息及其他盘的 Steam 游戏库；找到一处时自动选中并检查，找到多处时选择要使用的目录，找不到时保留「选择游戏目录」手动入口。然后点击「一键配置游戏」。配置自动处理匹配架构的官方加载器、Steam 启动和 MOD 支持组件，并显示进度；结束后重新检查真实状态。下载失败可以使用「高级维护 → 使用官方离线压缩包配置…」。配置期间禁止重复配置、切换目标游戏或更新 MOD。已就绪的环境可点「重新配置游戏环境」更新加载器与宿主；报告中的长路径可完整换行和选中复制，标题及关闭按钮保留在滚动区外。

配置就绪后，可安装当前作品或选择 `.lommod` 文件。MOD 列表独立保留，查看其他报告不会清空列表；安装、启停后自动刷新。更新当前作品保留已有安装文件名和启停状态。修复、回滚及手动宿主选择放在高级维护，已读记录单独管理。Mac 页面提供平台说明及素材、导出入口。

## 创作工具的操作结果

体检、统计、安装检查、内容包处理和离线模拟等操作完成后，会弹出结果窗口。先看窗口顶部的结果说明，再查看需要处理的项目；「安装状态：状态正常」表示安装检查未发现问题；更新宿主出现「内容已一致，无需更新，未修改文件」表示游戏内 DLL 与当前选定宿主目录相同，不保证所选源目录就是最新版，应使用本次完整编辑器旁的 `runtime`；「已在游戏中验证：否」仍表示没有实机验证。问题中附带的剧情位置可点击返回修改。

耗时任务会先弹出进度窗口，可点「收起，继续编辑」；底部状态栏的「查看进度或结果」可重新打开，完成后会再次提示。关闭结果窗口后，各工具页面底部也可重新打开最近一次报告。需要排查时可点击「复制诊断信息」，取得完整原始报告。

帮助窗口按主题逐页阅读，包含第一段剧情、人物与对白、同时动作、黑幕换景、素材、分支与结束、检查结果、预览与试玩、术语和快捷键十个主题，提供操作顺序与示例。「步骤查询」按分类列出全部 67 类步骤，显示用途、表单填写提示和相关教程；API 与内部字段默认收在折叠的技术参考中。搜索无结果时会提示缩短关键词或切换页签；清空搜索可恢复目录。顶部「帮助」或 F1 可进入同一窗口。内部诊断数据通过复制入口提供。

场景选择器包含已核实的 226 个背景及黑、白两种纯色，共 228 项。截图中的崆峒夜景选择“崆峒·练武场·夜晚”（`section_001_center_night`）；“崆峒·练武场2·夜晚”是另一个近景。

背景编号存在但预览缺图时，使用下面的一键提取，或选择此前已完整提取的预览素材库。旧版编辑器内置清单漏项需要更新软件；只更换素材库不会补齐旧版选择器。

## 大型剧情的编辑布局

「添加步骤」是可独立调宽、收起的常驻列，可以搜索并连续插入步骤。左侧章节／步骤栏同样可拖动边界调宽；底部「＋ 添加步骤」开关可重新打开步骤列。资源搜索选择框可拖动右下角调整宽度和高度，搜索、清空及重新打开后保持调整后的尺寸。音乐列表显示曲名和内部 ID，两者均可搜索。

步骤列表左侧勾选框可多选，Shift 连选、Ctrl 点选也可使用。拖动任一选中步骤可按原顺序批量移动；靠近列表上下边缘会自动滚动，蓝线表示放置位置。「…」菜单提供上移、下移、移到最前、移到最后和全选步骤。对白的「模式」放在表单最上方。

人物站位支持点击舞台示意图选左、中、右及两侧屏外位置。完整列表保留原版点位；横向百分比以左缘为 0%，脚底位置以画面顶部为 0%、底边为 100%，超过 100% 表示向画面下方偏移。

「结束剧情」的下一章节显示自定义名称与章节代码，保存和跳转仍使用章节代码。重复名称可按代码区分。

「剧情安排」旁的「初始设置」集中编辑开场时间、属性、好感、天赋、物品与旗标。它们仍是所选章节入口处的普通步骤，保存、撤销、导出共用同一份数据。每次播放该章节都会执行；原版附加剧情应按需要把开场事件设为仅一次。可切换目标章节，已有连续的入口设置也会显示在此。

## 原版剧情编辑与路线图

从 1.4.8 及更早版本升级，请下载完整包，原版章节与路线读取需要新版素材提取组件。

1. 选择「文件 → 原版剧情 → 导入原版章节 / 新建补丁…」，确认自己的游戏目录。
2. 在「原版章节」中选择目标章节，再搜索并选择要修改的对白或选项。
3. 需要改原文时勾选「修改这处原文」；需要加内容时填写「原句前新增对白」或「原句后新增对白」。
4. 按条件插入时勾选「仅在旗标检定成立时插入」，选择原版检查点、原版数值旗标或本 MOD 旗标，填写检定。可取反或进行数值比较。
5. 保存项目并导出 MOD，在游戏的「原版＋MOD」模式启用，需要 Host 1.4.9。

新增对白沿用该处人物和画面；条件不成立时继续执行原对白。修改选项文字会保留原选项对应的分支。左侧可添加其他原版补丁章节。支持撤销、重做和保存重开，原版文件不改写，导出包只包含修改片段与新增文字。

游戏更新导致原文定位失效时，编辑器保留旧修改并提示核对，运行时会报告定位失败。

选择章节后点击「导入整章到步骤编辑器」，把原章和已有修改转为普通步骤。可在步骤间加入演出、音乐、物品、数值和分支，导出后按原触发点覆盖执行。对白、人物演出等转换为已有表单，其他调用和赋值转换为有参数表单的「原版指令」；`if/elseif/else` 转换为「原版条件分支」，成立、不成立和汇合有各自的连线。选项键在表单中显示对应文字。原文仅作为来源数据保存，结构化步骤逐项生成执行代码。新增战斗的跨场景续接受局部状态限制，编辑器会提示。

整章导入的新增对白默认「沿用原版发言人与对白设置」，结束步骤默认「返回原版流程」。F5 从原版章节入口开始。原版来源只在每次加载作品后首次进入该章时逐字核对一次，播放时查缓存。未改的原版步骤隐藏 MOD 标识，改写和新增对白显示标识。人物、音乐、数值或流程产生持续影响后继续保留标识，删除或移动原版步骤、改写原生逻辑时按整章修改处理。导入原文保存在项目和包内，游戏更新后原文不一致需要重新导入核对。

原版已有的台词、人物演出和音乐调用随整章导入，不必逐句重填；资源仍引用本机游戏。此入口用于原章节的编辑与覆盖，目前没有把任意选段自动提取为独立新剧情的功能。只复用其中一段时，还需处理片段之前的人物出场、音乐设置、局部变量和分支依赖，不能只复制对白就保证完整还原演出。

游戏中进入原版剧情后按 **Ctrl+F6**，标记当前章节和对白。回编辑器选择「文件 → 原版剧情 → 打开最近游戏标记」，或在补丁面板的「游戏标记」中刷新并选择。已有补丁项目会定位已有章节或添加目标章节；切换其他项目时仍会提示保存。对白有多个相同位置时会提示选择，无法确认时只定位章节。

标记时同时读取任务入口数据。在「文件 → 原版剧情 → 原版路线图…」打开路线图，可缩放、拖动查看横向主线、分支合流及下方支线，按年份、月份、任务说明、地点、旗标或章节搜索。点击站点查看条件与去向，双击或点击「编辑这个原版章节」打开补丁；「编辑标记对白」直接定位最近标记。未列入任务表的已标记章节会单独显示。

路线图默认突出所选站点的来路与去向，可勾选「显示全部连线」。编号对应连线详情，悬停查看完整条件。流程图默认使用分支概览，连续演出合并成段，保留选项、检定、汇合和回环，选中的步骤单独显示；勾选完整流程可展开所有步骤。

红色「今」表示最近标记，金圈表示后续站点；勾号表示标记过，虚线只表示时间顺序。连线读取本机任务推进、场所检定配置和脚本中的调用关系。临时返回槽、场所结果和游历章节显示可证实的候选去向。Host 1.4.11 会记录当前会话的临时槽、游历目标及实际调用的下一章，路线图据此显示已观测的动态去向；退出游戏后记录失效。尚未执行、缺少上下文的分支保留候选状态。同一游戏版本下，刷新标记复用已读取的路线数据。标记不修改游戏存档或旗标，保存在 `%APPDATA%/lom_modkit/rust/story-bookmarks`；热键可在 Host 配置的 `General.StoryBookmarkHotkey` 修改。需要新版 Host。

## 人物旋转预览

人物旋转填写的是绝对目标角度，圈数会保留。从 0° 到 +355° 会逆时针转 355°，到 +360° 会转完整一圈；从 0° 到负角度则顺时针旋转。从 +355° 再到 +360° 只继续 5°，再次填写 +360° 不会额外转一圈，要继续一圈可填写 +720°。游戏中的大角度旋转需要 Host 1.5.2；旧 Host 仍按最短路径旋转。

人物旋转默认正角度逆时针，与游戏一致。在「人物旋转」步骤勾选「旧版旋转预览」，可使用旧版正角度顺时针的预览方式。开关会记住个人选择，剧情角度和导出结果仍按游戏规则执行。

## 数值与系统提示

属性设置／增减、好感、物品、天赋、奖励、结算奖励、活动奖励、敌方数值和使用消耗品提供「显示系统提示」开关。关闭后照常变更，只跳过自动提示；主动填写的对白、结算文字及动作后停留保留。新物品步骤开启时显示原版获得／失去提示，数量没有变化时不提示。新物品提示和静默回调需要 Host 1.4.9，导出会声明最低版本。

心上人可按人名选择，也保留自定义编号。属性设置无论是否显示提示都会写入数值，原「更新属性」旧字段继续读取；使用过该旧选项的作品重新导出后可修复只显示、不写入的问题。旧作品未填写新开关时保留原有提示方式。

## 图片和旧 Lua

「图片／标题显示」的普通图、物品图和大图提供官方图键搜索；展开「浏览图片缩略图」可以搜索、看图并直接应用。自定义图片步骤也有同样的缩略图入口。地图、家谱仍是原版点位演出；标题填写文字。大图背景色可选 0 白底、1 黑底、2 透明。自定义背景、全屏 CG、前景步骤可以直接「导入图片并用于此步骤」，之后调整位置、层级、比例、透明度和渐变时间。

「文件 → 打开」支持 UTF-8 Lua 文件。能完整确认的直线演出会转换为可编辑的场景、人物、表情、对白和等待步骤。混有时间、商店、物品等原版指令或异步演出时，会使用完整脚本解析器保留原调用、局部作用域和分支，同时拆出可识别的演出字段；仅改变朝向的 `stage.show`、`stage.showPortrait` 和对白中的 `setcharacter` 表情也可读取。无法完整表示的语法仍保留为一个高级 Lua 步骤，并显示原因；导入过程不执行 Lua，预览也不猜测动态分支。原始字节另存于 `assets/imported/source.lua`，保存时选择新的项目目录。复杂 Lua 的游戏效果仍需实机确认。

## 导入旧版散装剧情 MOD

在「文件 → 打开目录」选择单个 `Mods/<作品名>` 目录。没有 `manifest.json` 的旧目录会按 Binarizer Mortal ModSupport 的目录规则导入，读取 `CustomStory.csv` 的入口、标题和作者，以及 `StringTable.csv` 的完整文字键。`story/**/*.lua` 转为结构化步骤，保存时选择新的项目目录或 `.lommod` 文件。仅包含资源或数据表的作品会生成原版附加包。

导入的旧作品始终显示玩家 MOD 标识。兼容 PNG／JPG 立绘、GIF 序列帧、SpriteDesc、MP3 配音、`DataTable`、`LuaEquivalent/Condition`／`Switch`／`Position` 和原框架的只读 `ext.*` 查询。MP3 导入时转为包内 PCM WAV。数据表通过会话克隆应用，离开作品时恢复引用。原版模式中的资源／数据附加包每次只能启用一个来源，冲突时会列出作品名称。第三方作品仍需按实际内容验证。

## 一键提取预览素材

打开「文件 → 预览素材 → 从游戏提取预览素材…」，或右侧「人物立绘」缺图时的同名按钮；也可使用「素材管理 → 游戏预览素材 → 一键提取游戏资产」。首次选择包含 `Mortal_Data` 的游戏安装目录。兼容 x64 的 `StandaloneWindows64` 和旧版 `StandaloneWindows` 资源目录。程序只读取自己安装的游戏，提取立绘、表情、背景、官方插图／物品图／大图和心情气泡动画，默认把图片最长边缩到 1024 像素以用于预览，不导出音频、完整游戏脚本或模型。

「文件 → 预览素材 → 选择预览素材库…」用于载入已经提取完成、包含 `preview_map.json` 和 `assets/` 的整个文件夹，不是任意图片目录。这里若选中了游戏安装目录，也会自动进入提取流程。普通文件夹或不完整素材库会说明缺少什么、如何重新提取，并保留原先载入的素材库。未提取只影响编辑器预览，不妨碍试玩读取原版图片。

提取显示进度并支持取消。每次写入独立的本地素材缓存，原素材库不会被覆盖；完成后自动载入并记住新素材位置。部分失败时会列出失败素材，只引用已生成的图片；全部失败或取消时继续使用原素材库。游戏更新导致资源结构不兼容时会报错。

图片缓存位于 Windows 的 `%APPDATA%/lom_modkit/game-previews/extracted-*`，特效预览位于 `%APPDATA%/lom_modkit/effect-previews`。macOS 对应 `~/Library/Application Support/lom_modkit/`。这些图片只供本机预览，不会自动加入作品或发布包。导入作品的素材随作品保存。资源读取、提取使用 Rust，使用者无需安装 Python；组件缓存与素材缓存分开，正常更新编辑器会保留已提取素材。游戏更新后新增或改变的素材需重新提取。

预览提取器保留原版 Sprite 的完整画布和裁切偏移，保持各表情的尺寸关系。1.4.10 也会使用原版尺寸数据校正旧素材库的裁切立绘，修复角色显示过大的问题。游戏更新后如预览仍有差异，可重新提取当前游戏素材。

在「对白」中选择「旁白」或「居中旁白」，即可设置「旁白对齐」为「靠左对齐」；默认沿用游戏布局，设置只影响本句。

添加独立「人物换表情」步骤，选择已经登场的人物和新表情。旧表情淡出默认 0.5 秒，新表情淡入默认 1.5 秒，可以分别修改，0 表示立即完成该段。该步骤不需要对白，完成后才执行下一步；人物站位、朝向、偏移、旋转和压暗会保留。旁白可放在换表情后面。也能放进同时执行组，让两个人同时换表情。

在「对白」中设置「本句表情气泡」，可选择指定样式、跟随人物表情或本句隐藏；默认沿用已有设置。「气泡人物」默认使用发言人，旁白或沿用原版发言人时可指定已登场人物。本句结束后自动恢复此前气泡及偏移。单句设置需要 Host 1.4.10，导出时会提高最低 Host 版本。

添加「表情气泡」步骤，人物留空时，勾选或取消「显示气泡」控制全场自动气泡，持续到下一次设置；换章恢复章节的默认值。自动模式的图标由官方人物当前表情决定，Host 1.4.2 起，自定义人物也可按原版表情键自动匹配气泡。提取了新版气泡素材后，编辑器会显示动画预览。全场开关需要 Host 1.3.6 或更新版本，导出包会自动设置对应最低版本。填写「气泡执行后停留（秒）」可在显示、切换或隐藏气泡后停留，默认 0；连续两条气泡步骤分别设置样式和停留时间，即可编排转换，右侧播放也按设置停留。

Host 1.4.1 起，同一步骤可以指定原版人物，再选择「气泡样式」，直接显示叹号、音符、生气、汗滴等原版动画，不需要切换人物表情；只有 `normal` 立绘的配角也适用。取消「显示气泡」只隐藏这个人物的气泡；选择「跟随人物表情」恢复自动匹配。人物离场或换章时清除单人设置。人物留空时仍控制全场自动气泡，关闭全场会清除全部单人设置。1.4.2 起也可选择自定义人物，动画预览按原版关键帧及循环段播放。指定原版人物要求 Host 1.4.1，自定义人物气泡要求 Host 1.4.2。

## 特效预览与控制

不知道该配什么声音时，先查[原版特效与音效常用组合](effect_sound_combinations.md)，按场景选择可直接搜索的特效名与音效名。

添加「屏幕特效」，选择特效名，在右侧查看原版动画帧。首次使用点击「提取当前特效预览」：工具启动独立游戏测试场景，只生成当前预览缺少的特效，由游戏本身使用原版粒子、材质和贴图渲染；完成后自动载入，之后直接复用缓存并可离线播放，不必等待整套目录。需要 Windows 游戏与随包 Host 1.4.5，退出旧游戏进程后更新 Host。生成期间可以取消，不修改作者作品。素材页另有「提取全部原版特效（较慢）」供一次性补齐，已有特效不重复提取。

预览帧仅保存在本机 `%APPDATA%/lom_modkit/effect-previews`，不加入作品包或编辑器发布包；缺少缓存时会显示提取入口。编辑器对录制帧做平面位置／大小／旋转变换，采样视窗外的粒子无法在移动后补回；停止余粒使用单独录制的原版尾段，其采样相位不一定与任意停止时刻相同。精确随机发射、屏外粒子和停止过程请用 `F5` 检查。界面会区分真实结束和采样截断。

新步骤默认选择「画面百分比」：横向向右、纵向向下，左上角 0% / 0%，画面中心 50% / 50%，右下角 100% / 100%。可以输入小数和屏外位置。旧步骤保留「世界坐标」：中心 0 / 0、横向向右、纵向向上；默认舞台参考宽 19.2、高 10.8。切换模式会按这一参考舞台换算位置，游戏按实际舞台相机换算百分比；镜头移动或缩放后的结果请在游戏中确认。

- 「横向／纵向缩放倍数」分别控制大小：1 为原大小，负数翻转，0 隐藏。勾选「调整画面」后可选择特效、拖动定位和拉角等比缩放，选中框会显示正在调整的特效与标记；「位置归中」保留现有大小。
- 「旋转角度」是在特效原始朝向上追加 Z 旋转；「播放速度倍数」1 为原速、0 定格。调整速度不改变步骤的停留时间。
- 「自动停止（秒）」在后台计时，留空表示不限时；「动作后停留」决定何时执行下一步骤。例如自动停止 3 秒、停留 0 秒，会立即继续剧情，特效在 3 秒后停止。
- 「同名特效」选择「允许同名同时播放多个」可独立叠加，包括同一同时执行组中的多次播放；默认「同名只播放一个」继续复用。「实例标记」可给同一种特效分组，如 `left`、`right`；复用时按标记匹配，留空按名称匹配。「复用时重新播放」会清空旧粒子后从头播。
- 将「播放状态」设为「停止」：填写标记时停止该组全部实例，留空停止同名全部实例。「停止时清空残余」勾选后立即清空，未勾选则让已发射粒子自然消散。停止只影响本作品新接口创建的实例。

在同一同时执行组中，同名特效选择叠加时可以重复播放；复用同一实例，或同时播放并停止匹配实例，会提示冲突。新控制需要游戏 Host 1.4.5，退出游戏后在「游戏与 MOD」更新。纯旧章节保留旧调用；一章只要使用任一新特效字段，章内全部特效使用同一套新实例管理，以便后续停止能找到此前播放的特效。

## 多个动作同时执行

演出步骤可直接填写「动作后停留（秒）」，无需另插等待步骤。人物登场、退场、旋转、聚焦和压暗可勾选「等待动作完成」；新添加的登场／退场默认勾选，旧步骤未填写时保留原来的时序。原本会等待完成的移动等动作继续等待，再计算动作后的停留。在同时执行组内，每个动作完成自身动作和停留后，整组才继续。

在独立步骤列点击「同时执行多个动作」，或在演出分类中选择「同时执行组」。每张动作卡可以单独选择类型，编辑人物、站位、时长等原有字段；用「添加同时动作」加入更多动作，用「上移／移除」调整。组内至少 2 个、最多 32 个动作。

需要一次清除画面中的所有人物时，在「画面与声音」分类添加「清除画面人物」。「淡出时长」留空或 0 为立即退场，正数让所有官方和自定义人物一起淡出，人物气泡立即清除；淡出结束后，再计算「动作后停留」。设置淡出时长需要 Host 1.4.15 或更新版本；立即退场仍兼容 Host 1.4.11。

例如放两个「人物退场」，分别选择两人，淡出时长都设为 0.5 秒，就会一起开始退场；后面的对白等两人都退完才执行。也可以组合两人移动、转场与特效，或移动配合音效。音乐、普通音效和循环特效在启动后就算完成；想保留一段时间时，再加一个「等待」动作。

同一个已登场人物可以同时震动和显示气泡：组内添加「人物震动」与「表情气泡」，两项选择同一个人物，并在气泡中选择样式。同样支持气泡配合人物移动、位移、转向、旋转、换表情和恢复明亮；压暗时仍按原规则隐藏气泡。先让人物登场，再执行组合；登场／退场与该人物的气泡、两项同人物动画、两项同人物气泡，以及全场气泡开关与单人气泡，仍需拆成先后步骤。

人物移动和人物位移默认沿用该人物当前的表情，「人物立绘」页也显示这个继承结果。要修改，请在移动／位移前添加「人物换表情」，无需重新登场。

组内其余同人物动画或同一画面通道的冲突，体检会说明哪两个动作需要拆开。对白、选项、战斗和跳转放在组外。需要新背景和人物在揭幕后一起出现时：转场「淡入」盖黑幕 → 切换背景 → 用同时执行组摆好人物（淡入和移动时长均设 0）→ 转场「淡出」揭幕。

人物「压暗」是持续状态：开启后，后续对白、换表情、移动以及同时执行组结束均保留压暗；关闭后保持明亮。编辑器预览和从当前步骤试玩也保留前面的压暗设置。换章或离开舞台时清理该状态；旧项目需用新版编辑器重新导出，游戏侧同时使用随新版编辑器提供的 Host。

对白的「字号调节」可直接输入或拖动 0～200 的整数。0 使用游戏默认字号，其他值仅影响本句正文，姓名不随之缩放；右侧预览按相对大小显示。

组内修改与其他步骤一样可以保存、撤销和导出。选中步骤时，右侧显示整组完成后的画面；点击右侧「播放」，可预览人物同时移动、淡入淡出、偏移和旋转，每个动作按各自时长推进，等最慢的动作完成再继续。暂停后可以继续，手动切换步骤会停止播放。

黑幕会持续遮住换背景和人物就位的步骤，直到转场「淡出」揭幕；人物、对白和前景都绘制在黑幕后面，黑幕中不显示可点的选项。转场预览使用 1 秒示意，实际时长由游戏场景组件决定。Windows 从黑幕内步骤试玩时，前置画面也会恢复黑幕。

回忆、梦境、火光、模糊变暗四种滤镜支持编辑器近似预览：色调使用已核对的原版配置值，模糊和暗角为二维示意，不模拟真实景深和颗粒。从中间步骤试玩时，会按可达路径恢复之前分别开启或关闭的滤镜，再执行所选步骤；分支仍沿用当前预览的路径推算，无法恢复任意 Lua 的动态状态。自填的其他滤镜键可带入游戏，但编辑器不保证显示。音频、背景加载时序与最终画面仍需在游戏中确认。

## 设置与界面语言

macOS 从「屏幕顶部系统应用菜单 → 设置」打开设置，也可按 `⌘,`。其他平台使用窗口中的「设置」或 `Ctrl+,`。选择界面语言立即生效并记住偏好；这不会翻译作者写的台词，剧情翻译另用「编辑 → 多语言」。

界面支持简中、繁中、日文和韩文。原版指令表单、路线与流程图及原文章节面板使用稳定消息键，动态编号、条件值和作者文字通过命名参数插入。四语词典校验键集合、空译文和占位符，原版 API 名及资源编号保留在技术详情中。

## 在预览里摆放人物和插图（1.4.4）

在右侧「画面预览」勾选「调整画面」，点击人物或自定义插图选中它，也可从旁边的列表选择。拖动主体改变位置，拉动四角等比缩放；人物缩放时保持脚底位置，插图缩放时保持对角位置。点「复位」恢复该人物或图片的默认位置和 100% 本次缩放。调整时暂停播放，按 Esc 取消尚未松手的拖动。

选中对象后，上方常驻显示「正在调整：人物／插图／全屏图片 · 名称」，画面内选中框旁也显示名字；换对象时一起更新。取消选择或对象离场后不保留旧提示。编辑「表情气泡」步骤时，预览会标出所属人物及气泡定位框；人物留空则明确显示「全场自动气泡」。这些提示不写入作品或导出画面。

松开鼠标后才写入作品，一次拖动对应一次撤销；保存、导出和重新打开均保留结果。人物调整在当前选中步骤后生成并选中「人物位移」。继续拖动会修改当前位移；切换到后面的对白再拖动会新增位移，前面的画面保持原布局。已有多分支步骤须先选中具体分支中的演出步骤，流程结束后不能追加位移；素材本身的默认体型保持原值；插图调整修改对应的显示步骤，因此引用同一步骤的后续画面一起变化。背景、原版书页和标题等固定布局不参与此操作。新增人物布局与插图自由位置需要 Host 1.4.4。

## 立绘、表情与气泡对齐（1.4.6）

在「素材管理 → 作品素材」选择人物，展开「立绘、表情与气泡对齐」，选基准表情后点击「一键自动对齐全部表情」。未校准的基准图先按可见中心和底边归位，其余表情沿用基准位置；透明留白不参与对齐。需要时点击「当前表情贴底」，再拖动立绘或修改位置、缩放。半透明图用于对照，原图片保持不变。

自定义人物可点击「气泡自动对齐」，勾选「调整气泡锚点」后拖动微调。气泡沿用基准表情锚点，随人物移动、缩放和转身；原版人物的气泡在演出步骤的画面预览中调整。

画面预览勾选「调整画面」后，可对选中对象靠左、居中、靠右、靠上或贴底，按可见边缘计算。拖动靠近边缘或中心时吸附，按 Alt 暂停吸附；点击对象后，方向键微调 1 个舞台像素，Shift 为 10。布局可复制到同类对象；特效需使用相同坐标模式。操作支持撤销、重做和保存。表情校准需要 Host 1.4.6。

## 流程图与错误定位

右侧「流程图」按连接关系分层排列步骤：分支排序减少交叉，连续步骤对齐，汇合接续，跨层连线走预留通道，回路在节点外绕回。路线图相邻节点优先直连，自循环在站点旁就近绕回；两种图统一采用圆角折线和实心箭头。上方「−」「＋」调整缩放，「适应宽度」便于查看较宽的分支，「定位选中」把当前步骤滚动到可视区域。点击图中节点会选中左侧对应步骤并打开中间表单；从左侧切换步骤时，图也会定位到新选择。

连线显示选项或条件说明，缺失目标会明确标红。`F6` 编译失败时，能识别具体步骤的诊断提供章节/步骤链接；点击可定位到对应表单。图形显示和静态检查不代表游戏运行已通过，离线结果中的 `unknown` / `unsupported` 仍需按提示进一步验证。

## 一次打开多个章节

把 `main.json`、`story2.json`、`story3.json` 放在同一个文件夹，用「文件 → 打开目录…」选择这个文件夹。左上角章节下拉框会列出全部剧情，切换章节会保留其他章节的编辑内容。同目录的 `.lommod` 不作为章节载入；无关配置不要混放在剧情目录。

也支持选择含 `manifest.json` 和 `story/` 的标准项目根目录：读取 `story/` 内的剧情，并保留现有发布信息、战役身份和触发器；入口优先使用 Manifest 的 `entry`，没有匹配入口时使用排序后的第一章。「打开 JSON / Mod 包…」可打开单个 JSON 或整个 `.lommod`；一次打开多个独立 JSON 请用目录入口。

文件夹项目中「保存全部章节」写回全部章节，保留原文件名，并保存 `manifest.json`、新模式的 `scenario.json` 和项目素材。新项目首次保存选择一个目录；「另存项目目录…」把全部章节和素材保存到另一个目录。

各 JSON 的内部章节 `id` 必须唯一，仅改文件名不能区分重复 ID。重复 ID、损坏剧情或空文件夹会报错，并保留当前编辑项目。保存到其他文件夹时，遇到不属于当前项目的同名文件会停止。写入失败会保留未保存标记；每个文件独立原子写入，已经成功写入的章节不会回滚。

保存回原项目时，会清理此前已保存、如今已从项目移除且内容仍匹配的旧章节和素材文件，例如撤销已保存的新章节或删除素材。外部改写的文件不会被静默删除；另存项目不会清理原目录。

## 决斗（Combat）

一对一原版 Combat。`character` 只决定对手姓名和四类动画；`background` 从官方
`views` 独立选择。对手 HP、气力、六维、评语、技能、行动概率由节点填写；只填写
对手最大血量/气力时，会以该最大值满血/满气开场，填写初始值才会覆盖它。
`player_*` 是赵活官方 `GameStat` 基准值，被动走 `FinalValue`。血量先按官方
`_playerTotalHealth` 从体力等换算；若填了 `player_max_health`，再把这个基准加在

战后写回战前基准。标题存档先选战役再进 001～020。

## 战役（Battle）

多人原版 Battle。每个附加阵营单独设人数，该方总人数 = 各阵营人数 + 具名角色。
不要再填 `friend_people` / `enemy_people`。可选：

- `title`：写入准备画面 `ReadyPanel` 那一行官方标题；
- `friend_health` / `enemy_health`：本次实例克隆 `HealthData` 后的基础血量；

地图、中立路人和技能预设不向作者暴露。`PlayerDie` 按原版只能重试或回标题。

## 1.4.2 素材检索与气泡位置

场景和决斗背景可展开「浏览图片缩略图」。CG 缩略图提供大图 CG、普通插图、物品图、功法图、养成插图和界面图片分类；搜索同时匹配名称、编号和已核实的剧情关键词。例如搜索「鹤舞」可以找到小梅教舞与崆峒大战的大图，场景背景中可找到教舞前后的鹤崖黄昏与夜晚。

人物搜索列表及表情、外观、屏幕特效、场景和图片等单选列表均可用 ↑ / ↓ 连续切换，预览随当前选择更新，列表保持展开。搜索后仅在匹配项中移动；手动输入 ID 时保留文字编辑按键。切换会修改当前步骤，可用撤销恢复。

Host 1.5.13 起，「普通图片」「物品图」「事件图」「大图」都能选择作品图片，以及已导入的物品、消耗品和功法图标。下拉列表与缩略图库共用资源；图库可选「作品素材」分类，也可点「导入图片并用于此步骤…」直接导入并绑定。物品图沿用原版图框，无需再把物品图标导入一次。

自定义人物在「作品素材」中设置「气泡横向位置（%）」和「气泡高度（%）」。两项范围为 0～100，横向从原图左缘算起，高度从脚底算起，默认 50、90。位置跟随立绘朝向、缩放、位移与旋转。压暗、淡出和离场会隐藏气泡，恢复明亮后按当前设置显示。自动模式使用 shock、silent、laugh1 等原版表情键匹配。

「游戏与 MOD」显示编辑器、随包 Host 和游戏已安装 Host 的版本。启动编辑器时会自动同步已安装的 Host，覆盖解压更新也适用。游戏运行时会提示先退出，再点击「更新游戏 Host」完成同步。

每个「表情气泡」步骤还可设置「气泡横向偏移」「气泡纵向偏移」，原版与自定义人物均可使用。偏移基于 1920×1080 参考像素，正 y 向上，x 随人物朝向镜像。在画面预览中拖动蓝色定位框即可调整；图标播放结束后定位框仍可拖动。「气泡位置归位」恢复该人物默认位置，临时偏移随离场、换章或关闭全场清除。使用气泡偏移需要 Host 1.4.2。

Windows 新版 exe 已内置 Rust 气泡动画提取器。旧安装升级时直接换用新版 exe，再提取气泡动画即可。

## 书页事件图

1. 添加「图片/标题显示」步骤，动作选择「显示」，类别选择「事件图（书页）」。
2. 在图片选择器中选择原版事件插图，或点击「导入图片并用于此步骤…」。已导入的自定义图片也可从列表中选择。
3. 图片会保持比例完整放入书页左侧图框。横图会在图框内留出上下空间，竖图会按可用高度调整。
4. 「右侧题字」留空时显示“事件”，填写后使用自己的题字。
5. 「淡入时长（秒）」控制整张书页、图片和右侧题字从透明到完整显示的时间，例如填 0.8。留空或 0 为立即显示；淡入完成后才执行下方文字或后续步骤。
6. 「下方文本框」填写对白或补充文字后，游戏会显示底部文本并等待点击继续。留空时只显示书页，可用「动作后停留」或后续步骤控制展示时间。
7. 需要关闭时，再添加同类别的步骤，动作选择「隐藏」。

书页显示后会持续到隐藏或演出清理，因此可以在其后继续安排对白。使用这项功能的作品要求游戏接入组件 1.4.2。

设置正数淡入时间需要游戏接入组件 1.4.19，作品包会自动声明这一要求；旧组件会明确提示更新。旧作品没有此字段时保留立即显示的效果，从后续步骤开始试玩时直接恢复已显示的书页，不重复播放之前的淡入。

## 报错后修改哪里

已支持格式的旧版项目和 `.lommod` 应直接打开，保留原章节、素材和源码；重新导出时使用当前版本的生成逻辑。新版本增加的创作校验若发现旧值需要补填，应定位到相应步骤供修改，不应因此把旧作品挡在打开阶段。打开、另存或导出到新位置不会改写原包。

错误提示直接说明发生了什么、下一步怎么处理。有来源信息时提供对应修改入口；文件路径、内部调用与退出码保留在「复制诊断信息」中，供反馈排查使用。尚不支持的动态声音需要进入游戏确认，不能试听不代表作品里的音效丢失。

| 提示对应内容 | 点击后的位置 |
| --- | --- |
| 剧情步骤 | 打开所在章节，选中出错步骤 |
| 作品信息 | 打开作品设置，展开并定位已识别的字段 |
| 图片、人物或音频素材 | 打开对应作品素材或素材页面 |
| 游戏安装或预览提取 | 打开相关配置页面 |
| 作品文件打开失败 | 重新选择要打开的作品 |

例如导出时提示“还没填写存档身份”，点击「去填写存档身份」即可直接输入。存档身份使用小写英文字母、数字、下划线或短横线，长度为一至六十四个字符。已有玩家存档的作品沿用原编号。

没有具体编辑位置的系统错误保留具体原因和诊断信息，不显示无效的定位按钮。需要协助排查时，点击「复制诊断信息」取得完整原始错误。

### 无对白气泡与人物亮暗

添加“压暗”步骤，关闭“压暗”，生效方式选“下一句对白恢复自动”，再播放气泡。人物会临时高亮，到下一句对白时重新按说话人自动亮暗。

若已经使用过“持续保持”，添加一个“压暗”步骤，生效方式选“立即恢复自动”，即可解除固定亮暗。旧作品保留原有的持续设置。新方式需要 Host 1.5.1。

### 陌生人呼救或千里传音

新增“对白”，模式选“画外音（无立绘）”，直接填写台词。姓名留空显示“？？？”，也可以填写“远处的声音”等名称。这个模式不会把之前叫“？？？”的人物立绘带出来；原来已经在舞台上的其他人物会保留。需要 Host 1.5.1。

### 自定义大图与纯白屏（Host 1.5.9）

添加「图片/标题显示」，类别选「大图」。图片列表同时列出原版和作品图片；自有图片先从素材管理导入。勾选「只显示底色（不放图片）」后不需要图片，底色填 `0` 为白、`1` 为黑、`2` 为透明。淡入时长默认 1 秒，先显示底色，再显示图片；纯底色只执行第一段。需要屏幕逐渐变白时，勾选只显示底色、底色填 `0`，再设置淡入时长。要恢复原画面，添加同类别的隐藏步骤。

## 合并多个项目

从「文件 → 合并其他项目…」选择项目目录、章节 JSON 或 `.lommod`。同玩法的作品可合并；章节、素材和事件的内部引用随重命名调整，当前作品的名称与存档身份继续使用。附加剧情保留各自事件，独立作品添加入口选择。合并后需另存项目目录，再导出一个 `.lommod` 给玩家；两个原工程保留，合并操作可以撤销。旧式运行时扩展、原始 Lua 或整章原版代码不能自动合并，会说明具体章节；同一个原版人物的两份扩展需先人工整理。

合入项目的变量、任务和私有记录使用独立前缀，避开当前项目已有名称。加前缀后超过64位的变量或任务名会提示原名称并取消本次合并，请缩短后再合并；不会截短名称而把两个状态混为一项。

编辑换表情、移动等人物动作时，当前操作人物在预览中临时变亮；同时执行组以正在编辑的动作为准。该高亮不写入作品，不参与导出、游戏试玩的舞台恢复或连续播放中的明暗判定。
