# 项目模板

编辑器“文件 → 从模板新建…”提供五个起点：

| 模板 | 内容 |
|---|---|
| 空项目 | 一个安全 `end` 节点，从零搭建 |
| 线性对白 | 官方人物登场、角色对白、旁白、结束 |
| 分支剧情 | 双选项、两条路线、汇合结尾 |
| 自定义人物展示 | `user:template.hero` 的登场、对白、移动、退场 |
| 用户内容展示 | 自定义背景、BGM、音效、CG、配音 |

模板生成后就是普通 `story_schema` JSON，节点与手工添加的节点完全相同；没有模板运行时、隐藏字段或专用 DSL。五个模板都会通过 Story 校验和 Lua 编译，最后都有安全结束节点。

后两个模板的 `user:template.*` 是语法合法但故意不存在的占位内容 ID。它们用于展示字段连接方式，不会伪造本机资源；导出前必须在用户内容库创建对应内容，或把每个引用替换为已有内容。打包器仍会按正常规则拒绝缺失资源。

从模板创建的项目没有正式写入路径，并立即标为未保存。创建动作不会写任何 `story.json` / `.lommod`，后续由作者明确另存或导出。
