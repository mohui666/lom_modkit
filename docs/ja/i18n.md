# 多言語（i18n）

> 言語：[简体中文](../zh_CN/i18n.md) · [繁體中文](../zh_TW/i18n.md) · 日本語（本文） · [한국어](../ko/i18n.md)

カバー範囲は 2 つ：**エディターの UI**（`editor/i18n/`、Python）と**ゲーム内 Mod メニュー**
（`runtime/MortalModHost/src/I18n.cs`、C#）。両者は独立した実装で、互いに影響しません。

対応言語：簡体字中国語 `zh_CN`（既定／フォールバック）、繁体字中国語 `zh_TW`、日本語 `ja`、韓国語 `ko`。

## 1. エディターの UI

エディターのメニュー「言語」で切り替え、設定はプリファレンスに保存（`save_pref("language", code)`）され、
次回起動時に自動復元されます。切替後は `models.refresh_labels()` がノード要約などの文案を更新し、
Qt 内蔵コントロール（OK／キャンセルなどのシステムボタン）用に対応する `qt_<lang>` 翻訳パッケージを読み込みます。

### 1.1 ディレクトリ構造

```text
editor/i18n/
  core.py            # 加载/查询/回退逻辑（唯一入口）
  locales/<lang>.json  # 界面文案，扁平 key（app.title、menu.file…），缺 key 回退 zh_CN
  terms/<lang>.json    # 游戏名词对照，{类别: {内部id: 译名}}，缺项回退 zh_CN
  help/<lang>.html     # F1 帮助页，缺语言回退 zh_CN
```

### 1.2 クエリインターフェース（editor/i18n/core.py）

- `t(key, default=None, **kwargs)`：UI 文案を参照。現在の言語に欠落 → zh_CN →
  default → key 自体。`kwargs` は `str.format` を通り、プレースホルダーの書き間違いでもクラッシュしません。
- `term(category, item_id, default=None)`：一覧カテゴリ + 内部 id でゲーム名詞を参照
  （例：`term("characters", "brother4")` → 唐惟元）。現在の言語に欠落または空 →
  zh_CN → default → id 自体。
- `help_html()`：現在の言語でヘルプページ HTML を読む。キャッシュ付き。
- `set_language(code)`：未知のコードは一律 zh_CN にフォールバック。エラーにしません。
- PyInstaller 凍結形態では `_MEIPASS/i18n/` からファイルを読みます（`lom_bundle.spec` で同梱）。

terms のカテゴリは全 10 個で、`data/editor_data.json` の一覧と一対一で対応します：
`characters / stats / positions / views / free_positions / talents /
items_book / items_misc / items_special / common`。

### 1.3 ゲーム名詞の由来と再生成

名詞対照は `tools/extract_i18n_terms.py` が生成します。優先順位：

1. **LoM-wiki**（<https://github.com/mohui666/LoM-wiki-CNS>）：人物、門派、
   汗青書／生死簿、属性などは wiki の訳名を優先。
2. wiki にない項目は、**ゲーム解凍の公式言語表**にフォールバック
   （`lom_unpack/raw/*_zh-cn.txt` / `*_zh-tw.txt` / `*_kr.txt`、
   ディレクトリは環境変数 `LOM_UNPACK_DIR` で指定）。

公式ゲームの UI は繁体字・簡体字・韓国語のみで、**日本語はありません**：日本語の人物名は wiki 日本語ページ由来
（漢字は繁体字と同形）、属性名は wiki 日本語の施設ページの訳法由来（スクリプト内の `WIKI_JA_STATS`
にハードコード）。韓国語はすべて公式解凍データ由来です。

### 1.4 新しい言語の追加

1. `core.py` の `LANGUAGES` と `_QT_QM` にそれぞれ 1 行追加。
2. `locales/<lang>.json` / `terms/<lang>.json` / `help/<lang>.html` を新規作成
   （一部だけ訳してもよい。欠落項目は自動で zh_CN にフォールバック）。
3. UI コードは一律 `t("...")` / `term(...)` で文案を取得し、文字列をハードコードしません。

## 2. ゲーム内 Mod メニュー（ランタイムプラグイン）

`runtime/MortalModHost/src/I18n.cs`：メニュー文案（`entry`/`section.campaign`/
`section.play`/`campaign.start`/`play`/`close` など 11 個の key）は**ゲームの現在の言語**に従います——
リフレクションで LeanLocalization の `CurrentLanguage` を読み（読めないときは
`GetFirstCurrentLanguage`）、言語名を曖昧マッチ（tw/hk/繁→zh_TW、kr/ko/한→ko、
ja/日→ja、その他→zh_CN）。4 言語カタログはプラグインに内蔵（日本語を含む）。公式ゲーム自体に
日本語オプションはないため、日本語カタログが実際に発火することはありません。検出失敗（リフレクション例外、
フィールド改名）時は一律 zh_CN にフォールバックし、プラグインのその他の機能には影響しません。

## 3. 注意

- 多言語が影響するのは**UI とメニュー文案のみ**です。シナリオ JSON、`.lommod` パッケージ、Lua 成果物には
  言語情報を含まず、プレイヤーがどの言語を使っても mod の内容には影響しません。
- ノード id、スクリプト id、コンテンツ id などの内部識別子は翻訳対象外です。

## 4. ドキュメントの多言語

ドキュメント構成は Docusaurus / Kubernetes の per-locale ディレクトリ規約を参考にしています：言語ごとに 1 ディレクトリ、
**簡体字 `zh_CN/` が権威版**（内容を変えるときはまずこれを変更）。訳文は同名ファイルで配置します：

```text
docs/README.md            # 文档索引（语言导航 + 读者向导）
docs/zh_CN/<name>.md      # 权威版
docs/zh_TW/<name>.md      docs/ja/<name>.md   docs/ko/<name>.md
docs/research/            # 逆向研究材料，仅存档，不翻译
README.md                 # 简中权威版（GitHub 首页）
README.zh_TW.md  README.ja.md  README.ko.md   # 仓库根译文
```

規約：

- 各ドキュメント冒頭に言語切替行があり、リンクは所在ディレクトリ基準の相対パス
  （`docs/zh_CN/` 内では `../<lang>/` を指し、訳文ディレクトリ内では `../zh_CN/` に戻る）。
- 訳文が翻訳するのは prose のみ：コード、コマンド、パス、API／識別子、プログラム固定出力のエラーメッセージは
  原文を保持。
- ゲーム名詞の訳名は `editor/i18n/terms/<lang>.json` を正とします（エディター UI と一致）。
- ドキュメント間リンクは同一言語・同一ディレクトリの訳文を優先。そのドキュメントに訳文がない場合のみ `zh_CN/` を指します。
