# ソフトウェア利用ドキュメント

このページはエディター操作を説明します。スクリプトフィールドは [スクリプト / API ドキュメント](script_reference.md) を参照してください。エディターの「ヘルプ → ドキュメント」でも二つの独立タブに分かれています。

## 基本フロー

左側でチャプターとノードを構成し、中央で編集、右側でプレビューします。`F6` は通常検査、`Ctrl+F6` はリリース検査、`F5` は分離された一時テスト Mod です。公式 ID は読みやすい名前付きで表示されますが、保存されるのは安定 ID だけです。音声・画像・カスタムキャラクターは「ユーザーコンテンツ」から種類を選んで一元管理します。

## Combat と Battle

- `combat` は原作の一対一 Combat。相手テンプレート、HP、スタミナ、能力、奥義、才能、行動確率を設定できます。
- `battle` は原作の複数人 Battle。味方・敵・中立の編成、人数、NPC HP、プレイヤースキルを設定できます。
- 検証済み原作 API のみを使用し、独自マップ、モデル、AI、Battle Engine は作りません。

## MOD キャンペーンのセーブ分離

タイトルの「MOD キャンペーン開始」は原作ロード画面を再利用します。既存セーブを続行でき、「新規キャンペーン」空きスロットから Mod を選択できます。

- 原作手動スロットは `001`～`020`、MOD は `mod_<mod_id>`。
- MOD 自動セーブは `mod_<mod_id>_auto*`。原作 `auto*` へは書きません。
- Universe の最近スロットは最後の原作スロットのままなので、原作「続きから」が MOD に入ることはありません。
- 永続変数 sidecar は MOD ID とスロットで分離し、完全なパッケージ指紋を照合用に記録します。同じ ID の更新パッケージはキャンペーン状態を引き継ぎます。

MOD 再生中は会話本文の下中央に、文字を隠さない半透明の一行「非公式」表示を置きます。重要カードと画面全体にも出所表示があります。
