`combat` は一対一 Combat の相手設定、`battle` は複数人 Battle の三陣営設定です。`battle_setup` は旧 Battle 互換ノードです。公式リソースは読みやすい表示名を示しますが、JSON には安定 ID だけを保存します。ユーザーコンテンツは `user:<id>` を使います。
