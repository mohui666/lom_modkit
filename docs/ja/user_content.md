# ユーザーコンテンツ庫（User Content Library）

> 言語：[简体中文](../zh_CN/user_content.md) · [繁體中文](../zh_TW/user_content.md) · 日本語（本文） · [한국어](../ko/user_content.md)

ローカル、オフライン、Mod 単位で自己完結。アカウントなし、オンラインマーケットなし、クラウド同期なし。

## インポート方法

1. エディターのメニュー **ファイル → ユーザーコンテンツ庫**。
2. 「音声を取り込む…」をクリックし、ローカルの `.ogg` または `.wav`（1 件 20MB 以下）を選択します。
3. 表示名、名前空間、内部名、用途（音楽 / 効果音 / 環境音）を入力します。
4. 安定した番号が得られます。例：`battle.ogg` をインポートすると：

```text
user:mohui.battle
```

名前空間は既定でローカルのユーザー名の安全な形式になります。変更可能です。同じ番号の再インポートは拒否され、暗黙の上書きを防ぎます。

## 対応フォーマット

| フォーマット | 説明 |
| --- | --- |
| `.ogg` | Vorbis。初回再生時にごく短い読み込み遅延が起きることがあります。 |
| `.wav` | PCM 8/16 ビットまたは 32 ビット float。一般的な WAV は即時再生できます。 |

mp3 / flac / aac は非対応。ファイルサイズ上限は 20MB。

## ID とは

シナリオに保存されるのは参照であり、ファイルパスではありません。

- 公式の楽曲 / 効果音：従来どおり元の名前を書きます。例：`普通_001`、`鈴鐺_001`。
- ユーザーコンテンツ：必ず `user:<名前空間>.<名前>`。小文字の英字、数字、アンダースコアのみ。

表示名は中文でも構いません（「决战曲」など）。内部 ID にはスペース、中文、パスを含められません。

## ユーザーコンテンツの保存場所

開発時はローカルの以下にあります：

```text
%APPDATA%/lom_modkit/repository/audio/<id>/
  content.json
  音频文件
```

これはエディターのリポジトリにすぎません。PC を変えたり、`.lommod` だけを受け取ったプレイヤーにはこのディレクトリは不要です。

人物紹介画像 / 結末挿絵は引き続き `%APPDATA%/lom_modkit/assets/` にあり、シナリオには `assets/ファイル名.png` と書きます。既存の Mod を壊さないよう、本システムとは分離されています。

## Story に保存されるもの

音楽 / 効果音ステップの `name`：

```json
{ "type": "music", "name": "user:mohui.battle" }
```

`C:\Users\...\battle.ogg` のような保存は禁止です。

## エクスポート後もローカルのコンテンツ庫に依存しますか？

依存しません。エクスポートは**現在のシナリオが実際に参照している**ユーザー音声のみを `.lommod` にコピーします：

```text
assets/user/audio/mohui.battle/content.json
assets/user/audio/mohui.battle/battle.ogg
```

参照されていないインポート済み音声はパッケージに入りません。参照欠損、型の不一致、ファイル破損の場合、エクスポートは直接失敗します。

## Mod の共有方法

エクスポートした `.lommod` を相手に送るだけです。相手がインストールすれば、ゲームプラグインがパッケージ内から再生します。相手の PC にあなたのユーザーコンテンツ庫がなくても聴けます。

エディターの「Mod を読み込む」で他人のパッケージを開くと、パッケージ内のユーザー音声があなたのローカルリポジトリに登録され、引き続き編集しやすくなります。

## リソース削除の制限

ユーザーコンテンツ庫内では削除できます。現在のプロジェクトの音楽／効果音ステップがそのコンテンツをまだ使用している場合、削除は阻止され、どのチャプターのどのステップかが示されます。

## 台詞ボイス

`say` には任意フィールド `voice` を追加できます。値はユーザーコンテンツ参照でなければなりません：

```json
{ "type": "say", "character": "player", "text": "师兄，早。", "voice": "user:mohui.line_01" }
```

`voice` のないセリフは従来とまったく同じです。ある場合、そのセリフに入るときに前のセリフのボイスを停止して再生し、プレイヤーが次のセリフをクリックするか、シナリオが終了／中断したときに停止します。通常の効果音ノードは台詞ボイスを中断しません。

ボイスは独立した `audio` のままです。キャラの `content.json` には埋め込みません。音声 metadata には任意フィールド `character` を書けます。編集用の管理帰属であり、再生プロトコルは変わりません：

```json
{
  "schema": 1,
  "id": "mohui.line_01",
  "type": "audio",
  "name": "师兄早",
  "audio_kind": "sound",
  "files": { "main": "line_01.wav" },
  "character": "user:mohui.luoxue"
}
```

- カスタムキャラ詳細は「基本情報 / 立ち絵 / ボイス」の 3 タブです。
- 「ボイス」タブからの取り込みは現在のキャラに自動紐づけします。試聴・改名・紐づけ解除・削除もできます。
- ナレーション／システムボイスは `character` なしで構いません。旧音声にこのフィールドがなくても従来どおり使えます。
- 公式キャラ id（例：`player`）にも紐づけできます。ユーザーキャラオブジェクトは作りません。
- セリフステップのボイス選択：キャラ台詞は現在の話者に紐づいたボイスだけ選べます。ナレーションは未紐づけボイスだけです。未紐づけのキャラボイスは選べません。
- 削除時は従来どおり `say.voice` 参照を検査します。
- パックはストーリーが実際に参照している音声だけを集めます。キャラに未使用ボイスがぶら下がっていても同梱しません。

エディターのセリフステップで「台詞ボイス」を選ぶか、「インポート…」をクリックします（話者がいればそのキャラに自動紐づけ）。「クリア」でバインドを解除します。

## ランタイムの動作

- 共通画像は `type=image` と安定した `user:` 番号を使い、PNG/JPG/JPEG（8MB 以下）に対応します。背景・CG・Overlay は同じコンテンツ庫を共有し、一覧にはサムネイル、削除時には参照箇所を表示し、パックには実際の参照だけを収録します。

- 公式名：原版 Wwise。動作は従来とまったく同じです。
- `user:`：**現在演出中の .lommod** の中だけを探します。別の Mod が同名 ID を登録していても混線しません。
- カスタム音声は Windows `waveOut` で再生し、Unity `AudioSource` も Wwise も通りません。本ゲームのメインミックスは Wwise で、Unity で再生するとしばしば無音になります。
- 音量はおおよそゲームのマスター音量 × 音楽／効果音スライダーに従います。Wwise RTPC ではないため、完全一致はできません。
- カスタム fadeout は出力音量のフェードアウトです（その後もノードどおり待機します）。
- カスタム音楽への切替時は先に公式の背景楽を停止します。公式の `StopMusic` はもともと環境音も一緒にクリアします。
- カスタムキャラは独立 Runtime（`mod_char_*`）で、公式 Addressables には登録しません。show / say / hide / move / face / focus / offset / shock / dim / rotate に対応し、公式キャラの経路は変わりません。体型は `scale`（50–130、既定 100）で足元基準に縮小し、向きは `art_facing`（既定は左）の上にノードの `facing` を重ねます。
- `affinity` は純粋な演出ではなく公式 CharacterData の好感度を書き換えるため、カスタムキャラでは引き続き非対応です。長期状態には Mod 隔離変数を使用してください。
- 受け入れ確認には `samples/audio_test/` が使えます：自分で `user:test.bgm` / `user:test.sfx` / `user:test.env` をインポートしてください。
