# lom_modkit ドキュメント

権威版は簡体字中国語（`zh_CN/`）で、訳文は言語コードごとのディレクトリに同名で配置されています。
ドキュメントを変更する場合はまず `zh_CN/` を変更し、訳文を同期します。規約は [i18n.md §4](i18n.md) を参照。
