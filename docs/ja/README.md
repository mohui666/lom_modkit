`research/` は逆コンパイル研究資料（逆コンパイルスクリプトなど）で、アーカイブ専用、翻訳しません。

エディターで `Ctrl+Shift+F` を押すと、プロジェクト全体のチャプター、ノード、台詞、人物、素材、変数、Flag、遷移を検索でき、結果をダブルクリックして移動できます。「参照元を表示」で正確な参照位置も一覧できます。

「編集 → 一括編集」は、選択したノード間でフィールド名と schema 型が完全一致する安全な共通部分だけを編集できます。互換性のないフィールドは表示されません。

「編集 → ノードテンプレート」では、単一または連続したステップを保存できます。挿入ごとに新しいノード ID を生成してテンプレート内部の遷移だけを再マップし、外部遷移は維持します。同名の上書きとローカル絶対リソースパスは拒否します。

「編集 → ストーリーグループ」は、折りたたみ可能な Section / Group ツリーを提供します。情報は `_editor.sections` のみに保存され、ノード順、開始点、遷移は変更しません。グループの有無で生成 Lua は同一で、関数やサブルーチンの意味は持ちません。

「編集 → チャプター間コピー / 貼り付け」は、コピー先の ID 衝突を解決し、範囲内遷移を再マップして `user:` 参照を保持します。範囲外または欠落した参照は推測で変更せず、完了後に個別警告します。

「編集 → 変数 / Flag マネージャー」は、構造化シンボルの読取・書込・初回書込・確実な未使用・書込前読取の可能性を表示し、移動と参照検索を提供します。公式システムや Raw Lua を閉世界で判定できない場合は未知と明示します。

`F6` は日常用 Editing 検査、`Ctrl+F6` は公開用 Release 厳格検査です。両方ともコンパイル、フロー、コンテンツ参照、データフローを検査し、Release は公開 metadata と互換性規則も追加します。未使用コンテンツは自動削除せず、自動修復は物語の意味を変えない機械的変更だけです。

「ヘルプ → 診断バンドルを書き出す」は固定許可リストの ZIP を生成します。エディター/Runtime/ゲームのバージョン、Manifest、F6 結果、匿名化したプロジェクト件数、長さ制限済みエディタークラッシュログ、MortalModHost 関連だけを抽出した Runtime ログです。シナリオ本文、ユーザーコンテンツ庫、Mod、セーブ、個人ディレクトリ、無関係ログ、ゲームファイルは走査もコピーもしません。絶対パスとユーザー名はプレースホルダーへ置換します。

「編集 → 条件インスペクター」は branch を可読条件、シンボル、実際の分岐先として表示します。全 CFG 経路が同じ Mod Flag を先に書く場合だけ恒真を証明し、それ以外の Runtime 状態は未知のままにします。

「テストプレイ → ストーリーパスシミュレーター」は、到達不能、リンク切れ、出口なしループ、証明済みデッド分岐、終端なし、チャプター間遷移エラーを検査します。チャプター間の終端連鎖も追跡し、Raw Lua と未知の Runtime 状態を確定結果に見せません。

「テストプレイ → ストーリーテストランナー」は、JSON で初期変数/Flag、choice 操作、到達/状態アサーションを宣言します。確定意味論はオフラインで PASS/FAIL、骰子・Raw Lua・未知のゲーム状態は明示的に UNSUPPORTED です。
