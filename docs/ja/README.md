# 日本語ドキュメント

現在のバージョンは **1.6.7** です。集計、プレビュー、F5 での再読み込みを改善し、ゲーム内の名前に不足していた字形を補いました。MOD モードでは一部の能力値が 100 を超えられます。 [更新内容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.7)
