`research/` は逆コンパイル研究資料（逆コンパイルスクリプトなど）で、アーカイブ専用、翻訳しません。

エディターで `Ctrl+Shift+F` を押すと、プロジェクト全体のチャプター、ノード、台詞、人物、素材、変数、Flag、遷移を検索でき、結果をダブルクリックして移動できます。「参照元を表示」で正確な参照位置も一覧できます。

「編集 → 一括編集」は、選択したノード間でフィールド名と schema 型が完全一致する安全な共通部分だけを編集できます。互換性のないフィールドは表示されません。

「編集 → ノードテンプレート」では、単一または連続したステップを保存できます。挿入ごとに新しいノード ID を生成してテンプレート内部の遷移だけを再マップし、外部遷移は維持します。同名の上書きとローカル絶対リソースパスは拒否します。

「編集 → ストーリーグループ」は、折りたたみ可能な Section / Group ツリーを提供します。情報は `_editor.sections` のみに保存され、ノード順、開始点、遷移は変更しません。グループの有無で生成 Lua は同一で、関数やサブルーチンの意味は持ちません。

「編集 → チャプター間コピー / 貼り付け」は、コピー先の ID 衝突を解決し、範囲内遷移を再マップして `user:` 参照を保持します。範囲外または欠落した参照は推測で変更せず、完了後に個別警告します。

「編集 → 変数 / Flag マネージャー」は、構造化シンボルの読取・書込・初回書込・確実な未使用・書込前読取の可能性を表示し、移動と参照検索を提供します。公式システムや Raw Lua を閉世界で判定できない場合は未知と明示します。
