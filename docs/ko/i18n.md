# 다국어(i18n)

> 언어: [简体中文](../zh_CN/i18n.md) · [繁體中文](../zh_TW/i18n.md) · [日本語](../ja/i18n.md) · 한국어(본문)

두 부분을 다룹니다: **에디터 인터페이스**(`editor/i18n/`, Python)와 **게임 내 Mod 메뉴**
(`runtime/MortalModHost/src/I18n.cs`, C#). 둘은 독립적으로 구현되어 서로 영향을 주지 않습니다.

지원 언어: 간체 중국어 `zh_CN`(기본/폴백), 번체 중국어 `zh_TW`, 일본어 `ja`, 한국어 `ko`.

## 1. 에디터 인터페이스

에디터 메뉴 「언어」에서 전환하며, 설정은 환경 설정에 저장(`save_pref("language", code)`)
되어 다음 시작 시 자동으로 복구됩니다. 전환 후 `models.refresh_labels()`가 노드 요약 등 문구를
새로 고치고, Qt 내장 컨트롤(확인/취소 등 시스템 버튼)용으로 해당 `qt_<lang>` 번역 패키지를 로드합니다.

### 1.1 디렉터리 구조

```text
editor/i18n/
  core.py            # 加载/查询/回退逻辑（唯一入口）
  locales/<lang>.json  # 界面文案，扁平 key（app.title、menu.file…），缺 key 回退 zh_CN
  terms/<lang>.json    # 游戏名词对照，{类别: {内部id: 译名}}，缺项回退 zh_CN
  help/<lang>.html     # F1 帮助页，缺语言回退 zh_CN
```

### 1.2 조회 인터페이스(editor/i18n/core.py)

- `t(key, default=None, **kwargs)`: 인터페이스 문구 조회. 현재 언어에 없음 → zh_CN →
  default → key 자체. `kwargs`는 `str.format`을 거치며, 자리 표시자를 잘못 써도 크래시하지 않습니다.
- `term(category, item_id, default=None)`: 목록 카테고리 + 내부 id로 게임 명사 조회
  (예: `term("characters", "brother4")` → 당유원). 현재 언어에 없거나 비어 있음 →
  zh_CN → default → id 자체.
- `help_html()`: 현재 언어로 도움말 페이지 HTML 읽기, 캐시 포함.
- `set_language(code)`: 알 수 없는 코드는 일률적으로 zh_CN으로 폴백, 오류를 내지 않습니다.
- PyInstaller 동결 상태는 `_MEIPASS/i18n/`에서 파일을 읽습니다(`lom_bundle.spec`이 패키지에 넣음).

terms 카테고리는 총 10개로 `data/editor_data.json`의 목록과 일대일 대응합니다:
`characters / stats / positions / views / free_positions / talents /
items_book / items_misc / items_special / common`.

### 1.3 게임 명사 출처와 재생성

명사 대조표는 `tools/extract_i18n_terms.py`가 생성하며, 우선순위:

1. **LoM-wiki**(<https://github.com/mohui666/LoM-wiki-CNS>): 인물, 문파,
   한청서/생사부, 속성 등은 wiki 번역명을 우선 사용합니다.
2. wiki에 없는 항목은 **게임 언팩 공식 언어표**로 폴백
   (`lom_unpack/raw/*_zh-cn.txt` / `*_zh-tw.txt` / `*_kr.txt`,
   디렉터리는 환경 변수 `LOM_UNPACK_DIR`로 지정).

공식 게임 인터페이스에는 번체 중국어, 간체 중국어, 한국어만 있고 **일본어는 없습니다**: 일본어 인물명은 wiki 일본어 페이지에서
(한자가 번체 중국어와 같은 형태), 속성명은 wiki 일본어 시설 페이지 번역 방식에서 가져옵니다(스크립트 내 `WIKI_JA_STATS`
에 고정); 한국어 전문은 공식 언팩에서 가져옵니다.

### 1.4 새 언어 추가

1. `core.py`의 `LANGUAGES`와 `_QT_QM`에 각각 한 줄 추가.
2. `locales/<lang>.json` / `terms/<lang>.json` / `help/<lang>.html` 신규 작성
   (일부만 번역해도 되며, 없는 항목은 자동으로 zh_CN으로 폴백).
3. 인터페이스 코드는 일률적으로 `t("...")` / `term(...)`로 문구를 가져오고, 문자열을 하드코딩하지 않습니다.

## 2. 게임 내 Mod 메뉴(런타임 플러그인)

`runtime/MortalModHost/src/I18n.cs`: 메뉴 문구(`entry`/`section.campaign`/
`section.play`/`campaign.start`/`play`/`close` 등 11개 key)는 **게임의 현재 언어**를 따릅니다 —
리플렉션으로 LeanLocalization의 `CurrentLanguage`를 읽고(읽지 못하면
`GetFirstCurrentLanguage`), 언어 이름 퍼지 매칭(tw/hk/繁→zh_TW, kr/ko/한→ko,
ja/日→ja, 나머지→zh_CN), 4개 언어 목록은 플러그인에 내장(일본어 포함). 공식 게임 자체에는
일본어 옵션이 없어 일본어 목록은 실제로 발동하지 않습니다; 감지 실패(리플렉션 예외, 필드 개명) 시 일률적으로
zh_CN으로 폴백하며 플러그인의 나머지 기능에 영향을 주지 않습니다.

## 3. 주의

- 다국어는 **인터페이스와 메뉴 문구**에만 영향을 줍니다; 스토리 JSON, `.lommod` 패키지, Lua 산출물에는
  언어 정보가 없으며, 플레이어가 어떤 언어를 쓰든 mod 내용에 영향을 주지 않습니다.
- 노드 id, 스크립트 id, 콘텐츠 id 등 내부 식별자는 번역에 참여하지 않습니다.

## 4. 문서 다국어

문서 아키텍처는 Docusaurus / Kubernetes의 per-locale 디렉터리 약정을 참조합니다: 언어마다 디렉터리 하나,
**간체 중국어 `zh_CN/`가 권위 버전**(내용을 바꿀 때 먼저 이것을 수정), 번역문은 같은 파일명으로 보관합니다:

```text
docs/README.md            # 文档索引（语言导航 + 读者向导）
docs/zh_CN/<name>.md      # 权威版
docs/zh_TW/<name>.md      docs/ja/<name>.md   docs/ko/<name>.md
docs/research/            # 逆向研究材料，仅存档，不翻译
README.md                 # 简中权威版（GitHub 首页）
README.zh_TW.md  README.ja.md  README.ko.md   # 仓库根译文
```

약정:

- 각 문서 앞부분에 언어 전환 행이 있으며, 링크는 소재 디렉터리에 따라 상대 경로 사용
  (`docs/zh_CN/` 안에서는 `../<lang>/`로; 번역문 디렉터리 안에서는 `../zh_CN/`로 돌아감).
- 번역문은 prose만 번역합니다: 코드, 명령, 경로, API/식별자, 프로그램 고정 출력 오류 메시지는
  원문 유지.
- 게임 명사 번역명은 `editor/i18n/terms/<lang>.json`을 기준으로 합니다(에디터 인터페이스와 일치).
- 문서 간 링크는 같은 언어 같은 디렉터리의 번역문을 우선 가리킵니다; 해당 문서에 번역문이 없을 때만 `zh_CN/`로 돌아갑니다.
