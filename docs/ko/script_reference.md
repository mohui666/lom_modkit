# 스크립트 / API 문서

> **버전 안내:** 이 문서는 현재 Rust 버전과 아직 완전히 동기화되지 않았습니다. 이전 UI 메뉴와 구현 설명은 과거 버전의 참고 정보입니다. 최신 내용은 [중국어 간체 문서](../chs/script_reference.md)를 기준으로 확인하세요.

‘도움말 → 문서 → 스크립트 / API’는 실제 schema에서 생성되며 64개 노드마다 JSON 키, UI 의미, 필수 여부, 유형·열거형, 기본값, 최소 예제와 Runtime API를 표시합니다.

`combat`의 인물은 결투 이름과 전투 애니메이션만 결정하고 배경은 공식 `views`에서 별도로 선택하며 다른 값은 자유롭게 설정합니다. `battle`은 아군·적군 진영, 총인원, 확인된 공식 이름 있는 인물만 설정합니다. 이전 프리셋과 `battle_setup`은 삭제되었습니다. 사용자 콘텐츠는 `user:<id>`를 사용합니다.

## 동시 실행 그룹

`parallel`의 `actions`는 2~32개의 연출 동작입니다. `id/goto`는 상위 그룹에만 지정합니다. 모든 동작을 함께 시작하고 모두 끝나면 다음 단계로 진행합니다. 같은 인물이나 표시 채널을 동시에 제어하면 오류가 발생합니다. 인물 연출, 배경, 전경, 전환, 효과, 소리, 대기를 지원합니다. 대사, 선택지, 전투, 이동 분기, Lua 및 중첩 그룹은 그룹 밖에 두세요. 음악과 반복 효과는 시작 후 완료로 봅니다. 미리보기는 그룹 완료 상태를 표시합니다. 3/2/1 형식을 유지하며 실제 게임 연출은 아직 검증하지 않았습니다.
