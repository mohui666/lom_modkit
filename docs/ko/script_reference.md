# 스크립트 / API 문서

‘도움말 → 문서 → 스크립트 / API’는 실제 schema에서 생성되며 63개 노드마다 JSON 키, UI 의미, 필수 여부, 유형·열거형, 기본값, 최소 예제와 Runtime API를 표시합니다.

- [Mod v3 형식과 컴파일 규약](mod_format.md)
- [story_api / CLI](ai_cli.md)
- [다국어 규약](i18n.md)
- [현재 기능과 경계](current_capabilities.md)

`combat`은 1대1 Combat 상대 설정이고 `battle`은 다인 Battle의 세 진영 설정입니다. `battle_setup`은 이전 Battle 호환 노드입니다. 공식 리소스는 읽기 쉬운 표시명을 제공하지만 JSON에는 안정 ID만 저장합니다. 사용자 콘텐츠는 `user:<id>`를 사용합니다.
