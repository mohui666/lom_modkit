`research/`는 역공학 연구 자료(디컴파일 스크립트 등)로, 보관용이며 번역하지 않습니다.

에디터에서 `Ctrl+Shift+F`를 누르면 프로젝트 전체의 챕터, 노드, 대사, 인물, 소재, 변수, Flag와 이동을 검색하고 결과를 더블 클릭해 바로 이동할 수 있습니다. ‘누가 참조하나요?’로 정확한 참조 위치도 볼 수 있습니다.

‘편집 → 일괄 편집’은 선택한 노드 사이에서 필드 이름과 schema 유형이 정확히 같은 안전한 교집합만 편집하며, 호환되지 않는 필드는 표시하지 않습니다.

‘편집 → 노드 템플릿’에서 하나 또는 연속된 단계를 저장할 수 있습니다. 삽입할 때마다 새 노드 ID를 만들고 템플릿 내부 이동만 다시 연결하며 외부 이동은 유지합니다. 같은 이름의 덮어쓰기와 로컬 절대 리소스 경로는 거부합니다.
