# 한국어 문서

현재 버전은 **1.6.3**입니다. F8 도구에서 원작 대사와 관련 이야기, 사망 CG를 검색하고 날짜와 장 또는 장소를 함께 지정해 이동할 수 있습니다. [업데이트 내용](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.3)은 GitHub Release에서 확인할 수 있습니다.

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.

게임 환경을 다시 설정해 Host도 1.6.3으로 업데이트하세요. 사용법은 [F8 개발 도구](../chs/software_usage.md#游戏内-mod-工坊与开发工具)를 참조하세요.
