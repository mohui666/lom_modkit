# 한국어 문서

현재 버전은 **1.6.11**입니다. GIF 가져오기, 이야기 구간 녹화, 인물 전기와 관계 화면 썸네일 설정을 지원합니다. [업데이트 내용](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.11)

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.

게임 환경을 다시 설정해 Host도 1.6.11으로 업데이트하세요. 사용법은 [F8 개발 도구](../chs/software_usage.md#游戏内-mod-工坊与开发工具)를 참조하세요.
