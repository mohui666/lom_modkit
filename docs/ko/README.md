# 한국어 문서

현재 버전은 **1.6.2**이며 F8 도구의 4개 언어, 원작 이벤트 참조와 개발용 이동, 결투 전용 배경 28개와 소매 로딩 수정을 포함합니다. [업데이트 내용](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.2)은 GitHub Release에서 확인할 수 있습니다.

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.

게임 환경을 다시 설정하여 Host도 1.6.2로 업데이트하세요. [F8 언어와 개발 도구](../chs/software_usage.md#游戏内-mod-工坊与开发工具) 및 [결투 배경](../chs/software_usage.md#查找官方背景)은 사용 가이드를 참조하세요.
