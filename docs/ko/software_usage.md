# 소프트웨어 사용 문서

이 문서는 에디터 사용법을 설명합니다. 스크립트 필드는 [스크립트 / API 문서](script_reference.md)를 보세요. 에디터의 ‘도움말 → 문서’에서도 두 내용을 별도 탭으로 제공합니다.

## 기본 흐름

왼쪽에서 챕터와 노드를 구성하고, 가운데에서 편집하며, 오른쪽에서 미리 봅니다. `F6`는 일반 점검, `Ctrl+F6`는 출시 점검, `F5`는 격리된 임시 테스트 Mod입니다. 공식 ID 선택기는 읽기 쉬운 이름을 보여 주지만 저장 시에는 안정 ID만 기록합니다. 오디오·이미지·사용자 캐릭터는 ‘사용자 콘텐츠’에서 유형을 먼저 선택해 통합 관리합니다.

## Combat과 Battle

- `combat`은 원작 1대1 Combat으로 상대 템플릿, 체력, 기력, 능력, 필살기, 재능과 행동 확률을 설정합니다.
- `battle`은 원작 다인 Battle로 아군·적군·중립 편성, 인원, NPC 체력과 플레이어 기술을 설정합니다.
- 검증된 원작 API만 쓰며 사용자 지도, 모델, AI, Battle Engine은 만들지 않습니다.

## MOD 캠페인 저장 격리

타이틀의 ‘MOD 캠페인 시작’은 원작 불러오기 화면을 재사용합니다. 기존 캠페인을 이어 하거나 빈 ‘새 캠페인’ 슬롯에서 Mod를 선택할 수 있습니다.

- 원작 수동 슬롯은 `001`～`020`, MOD는 `mod_<mod_id>`입니다.
- MOD 자동 저장은 `mod_<mod_id>_auto*`이며 원작 `auto*`에 쓰지 않습니다.
- Universe 최근 슬롯은 마지막 원작 슬롯을 유지하므로 원작 ‘계속하기’가 MOD로 들어가지 않습니다.
- 영구 변수 sidecar는 MOD ID와 슬롯으로 격리하고 전체 패키지 지문을 확인용으로 기록합니다. 같은 ID의 업데이트 패키지는 캠페인 상태를 이어받습니다.

MOD 재생 중 대화 본문 아래 중앙에 글자를 가리지 않는 반투명 한 줄 비공식 표시가 있으며, 주요 카드와 전체 화면에도 출처 표시가 유지됩니다.
