# 軟體使用文件

本頁說明編輯器操作；腳本欄位與節點契約請查 [腳本 / API 文件](script_reference.md)。編輯器的「說明 → 文件」也將兩類內容分成獨立頁籤。

## 基本流程

建立或開啟專案，在左側編排章節與步驟、中間編輯欄位、右側預覽與檢查。`F6` 是日常體檢，`Ctrl+F6` 是發佈體檢，`F5` 產生隔離的臨時試玩包。官方 ID 下拉顯示可讀名稱，儲存時仍使用穩定 ID；音訊、圖片與自訂角色統一由「使用者內容」依類型匯入。

## 決鬥與戰役

- `combat` 是原版一對一 Combat：可選人物/場景範本，覆寫對手血量、體力、屬性、絕招、天賦與行動機率。
- `battle` 是原版多人 Battle：可分別選擇我方、敵方、中立陣容，設定人數、NPC 血量與玩家技能。
- 兩者只使用已驗證的原版介面，不建立自訂地圖、模型、AI 或戰鬥引擎。

## MOD 戰役存檔隔離

標題畫面的「開始 MOD 戰役」重用原版讀檔面板；已有戰役可繼續，空白「新戰役」槽會開啟戰役選擇。

- 原版手動槽為 `001`～`020`；MOD 的 001 對應 `mod_campaign_<campaign_id>`，002～020 對應 `_sNNN`，舊 `mod_<mod_id>` 不會被探測。已有槽可讀取或覆寫，空槽可在標題頁開始新戰役。
- MOD 自動槽追加 `_auto`、`_auto_free`、`_auto_battle`，不會寫入原版 `auto*`。
- 遊戲內讀檔入口預設進入當前 MOD 的次級存檔頁；空槽在此頁只可讀取，不會直接建立新戰役。
- Universe 最近槽保持最後一個原版槽，因此原版「繼續遊戲」不會進入 MOD。
- 持久變數 sidecar 依 MOD ID 與槽位隔離，並記錄完整包指紋供核對；同 ID 更新包沿用該戰役狀態。

MOD 演出時，對話框正文下方中央有不遮字的半透明單行來源標記；關鍵卡片與全域畫面也保留「非官方內容」提示。
