# 繁體中文文件入口

目前版本為 **1.6.4**。F8 工坊可搜尋原版對白、相關劇情與死亡 CG，並一併設定跳轉的日期與章節或地點。[更新內容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.4) 保留在 GitHub Release。

編輯器介面支援繁體中文。操作、格式與 API 文件統一維護最新版簡體中文，避免舊翻譯的選單與參數誤導。

升級後請重新配置遊戲環境以更新 Host 1.6.4。操作見 [F8 工坊與開發工具](../chs/software_usage.md#游戏内-mod-工坊与开发工具)。
