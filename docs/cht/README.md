# 繁體中文文件入口

目前版本為 **1.6.11**。支援匯入 GIF 動圖、錄製指定劇情片段，以及設定人物傳記和人際頁縮圖。 [更新內容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.11)

編輯器介面支援繁體中文。操作、格式與 API 文件統一維護最新版簡體中文，避免舊翻譯的選單與參數誤導。

升級後請重新配置遊戲環境以更新 Host 1.6.11。操作見 [F8 工坊與開發工具](../chs/software_usage.md#游戏内-mod-工坊与开发工具)。
