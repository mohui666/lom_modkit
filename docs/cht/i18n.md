# 多語言（i18n）

> 語言：[简体中文](../chs/i18n.md) · 繁體中文（本文） · [日本語](../ja/i18n.md) · [한국어](../ko/i18n.md)

涵蓋兩塊：**編輯器介面**（`editor/i18n/`，Python）與**遊戲內 Mod 選單**
（`runtime/MortalModHost/src/I18n.cs`，C#）。兩者獨立實作，互不影響。

支援語言：簡體中文 `chs`（預設/保底）、繁體中文 `cht`、日語 `ja`、韓語 `ko`。

## 1. 編輯器介面

編輯器選單「語言」切換，偏好存入偏好設定（`save_pref("language", code)`），
下次啟動自動恢復。切換後 `models.refresh_labels()` 刷新節點摘要等文案，
並為 Qt 內建控制項（確定/取消等系統按鈕）載入對應 `qt_<lang>` 翻譯包。

### 1.1 目錄結構

```text
editor/i18n/
  core.py            # 加载/查询/回退逻辑（唯一入口）
  locales/<lang>.json  # 界面文案，扁平 key（app.title、menu.file…），缺 key 回退 chs
  terms/<lang>.json    # 游戏名词对照，{类别: {内部id: 译名}}，缺项回退 chs
  help/<lang>.html     # F1 帮助页，缺语言回退 chs
```

### 1.2 Rust UI API

`rust/lom-editor/src/i18n.rs` provides `tr`, `key`, `term`, `set_locale` and `help_text`. JSON dictionaries, term tables and help HTML are embedded at compile time. `rust/lom-editor/data/native-translations.json` contains native UI additions. No Qt translation engine or external Python resources are needed at runtime.

### 1.3 遊戲名詞來源與再產生

名詞對照由 `tools/extract_i18n_terms.py` 產生，優先級：

1. **LoM-wiki**（<https://github.com/mohui666/LoM-wiki-CNS>）：人物、門派、
   汗青書/生死簿、屬性等優先用 wiki 譯名。
2. wiki 沒有的條目，退回**遊戲解包官方語言表**
   （`lom_unpack/raw/*_zh-cn.txt` / `*_zh-tw.txt` / `*_kr.txt`，
   目錄由環境變數 `LOM_UNPACK_DIR` 指定）。

官方遊戲介面只有繁中、簡中、韓語，**沒有日語**：日語人物名取 wiki 日文頁
（漢字與繁中同形），屬性名取 wiki 日文設施頁譯法（腳本內 `WIKI_JA_STATS`
寫死）；韓語全文來自官方解包。

### 1.4 Adding a language

Add its locale, terms and help files under `editor/i18n/`, then register them in `rust/lom-editor/src/i18n.rs`. Native labels belong in `native-translations.json`. Run `cargo test --locked -p lom-editor` to validate embedded dictionaries.

## 2. 遊戲內 Mod 選單（執行階段外掛）

`runtime/MortalModHost/src/I18n.cs`：選單文案（`entry`/`section.campaign`/
`section.play`/`campaign.start`/`play`/`close` 等 11 個 key）跟隨**遊戲當前語言**——
通過反射讀 LeanLocalization 的 `CurrentLanguage`（讀不到時
`GetFirstCurrentLanguage`），語言名模糊匹配（tw/hk/繁→cht，kr/ko/한→ko，
ja/日→ja，其餘→chs），四語言目錄內嵌在外掛裡（含日語）。官方遊戲本身沒有
日語選項，日語目錄實際不會觸發；偵測失敗（反射例外、欄位改名）一律退回
chs，不影響外掛其餘功能。

## 3. 注意

- 多語言只影響**介面與選單文案**；劇情 JSON、`.lommod` 包、Lua 產物不含
  語言資訊，玩家用什麼語言不影響 mod 內容。
- 節點 id、腳本 id、內容 id 等內部識別符不參與翻譯。

## 4. 文件多語言

文件架構參考 Docusaurus / Kubernetes 的 per-locale 目錄約定：每種語言一個目錄，
**簡中 `chs/` 是權威版**（改內容先改它），譯文同檔名存放：

```text
docs/README.md            # 文档索引（语言导航 + 读者向导）
docs/chs/<name>.md      # 权威版
docs/cht/<name>.md      docs/ja/<name>.md   docs/ko/<name>.md
docs/research/            # 逆向研究材料，仅存档，不翻译
README.md                 # 简中权威版（GitHub 首页）
README.cht.md  README.ja.md  README.ko.md   # 仓库根译文
```

約定：

- 每篇文件開頭有語言切換行，連結按所在目錄用相對路徑
  （`docs/chs/` 內指向 `../<lang>/`；譯文目錄內指回 `../chs/`）。
- 譯文只譯 prose：程式碼、命令、路徑、API/識別符、程式固定輸出的錯誤訊息
  保持原文。
- 遊戲名詞譯名以 `editor/i18n/terms/<lang>.json` 為準（與編輯器介面一致）。
- 文件間連結優先指向同語言同目錄的譯文；該文件無譯文時才指回 `chs/`。
