# 活侠传 · LoM Modkit

現在のバージョンは **1.6.11** です。GIF アニメの読み込み、物語の指定区間の録画、オリジナルおよび原作キャラクターの伝記とサムネイルの設定に対応しました。

エディターの日本語 UI は引き続き利用できます。操作・形式・API の最新情報は簡体字中国語の資料に統一しています。
