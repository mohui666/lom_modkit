# 活侠传 · LoM Modkit

現在のバージョンは **1.6.13** です。追加エピソードの設定に原作の章を使う条件の案内を追加し、書籍プレビューで作品の画像を選んで移動する手順を案内します。

エディターの日本語 UI は引き続き利用できます。操作・形式・API の最新情報は簡体字中国語の資料に統一しています。
