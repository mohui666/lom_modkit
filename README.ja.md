# 活侠传 · LoM Modkit

現在のバージョンは **1.6.8** です。決闘と戦役ごとに原作曲や作品の音楽を設定できます。『活俠傳』1.0.6001.2 のバックグラウンド動画書き出しにも対応しました。

エディターの日本語 UI は引き続き利用できます。操作・形式・API の最新情報は簡体字中国語の資料に統一しています。

[エディターをダウンロード](https://github.com/mohui666/lom_modkit/releases/latest) · [中国本土向けミラー](https://toolbox.mahui.site/downloads/lom-modkit/v1.6.8/lom-editor.exe) · [更新内容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.8) · [最新ドキュメント](docs/ja/README.md) · [README](README.md)

ゲームを終了してから「ゲームと MOD」で環境を再設定して Host を 1.6.8 に更新し、ゲームを起動し直してください。
