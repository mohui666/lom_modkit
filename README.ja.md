# 活侠传 · LoM Modkit

現在のバージョンは **1.6.7** です。長い章の集計、舞台プレビュー、パッケージ検証、F5 での再読み込みを高速化しました。ゲーム内の名前に字形がない場合は近い書体で補い、MOD モードでは一部の能力値が 100 を超えられます。

エディターの日本語 UI は引き続き利用できます。操作・形式・API の最新情報は簡体字中国語の資料に統一しています。

[エディターをダウンロード](https://github.com/mohui666/lom_modkit/releases/latest) · [中国本土向けミラー](https://toolbox.mahui.site/downloads/lom-modkit/v1.6.7/lom-editor.exe) · [更新内容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.7) · [最新ドキュメント](docs/ja/README.md) · [README](README.md)
