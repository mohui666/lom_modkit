# 活侠传 · LoM Modkit

現在のバージョンは **1.6.5** です。ゲーム内の F8 ツールで原作のセリフや関連シナリオ、死亡 CG を検索できます。日付と章または場所を組み合わせて移動できます。キャラクターの移動時に設定済みの縦方向のオフセットを引き継ぎます。

エディターの日本語 UI は引き続き利用できます。操作・形式・API の最新情報は簡体字中国語の資料に統一しています。

[エディターをダウンロード](https://github.com/mohui666/lom_modkit/releases/latest) · [更新内容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.5) · [最新ドキュメント](docs/ja/README.md) · [README](README.md)

ゲームを終了してから「ゲームと MOD」で環境を再設定して Host を 1.6.5 に更新し、ゲームを起動し直してください。
