# 活侠传 · LoM Modkit

目前版本為 **1.6.2**。遊戲內 F8 工坊支援四語介面、原版事件與前後任務參照、條件說明及日期／章節跳轉；加入 28 張決鬥專用背景，修復小梅決鬥載入衝突，並以 Rust 原生元件改善執行時計算。

編輯器介面支援繁體中文。操作、格式與 API 文件統一維護最新版簡體中文，避免舊翻譯的選單與參數誤導。

[下載編輯器](https://github.com/mohui666/lom_modkit/releases/latest) · [更新內容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.2) · [最新文件](docs/cht/README.md) · [README](README.md)

升級後請退出遊戲，在「遊戲與 MOD」重新配置遊戲環境，將 Host 更新至 1.6.2。已有素材庫可補充提取決鬥背景縮圖。F8 工具語言可獨立選擇，不改變遊戲或作品對白語言；跳轉不會補齊之前的劇情歷史。
