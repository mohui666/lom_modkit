# 活侠传 · LoM Modkit

目前版本為 **1.6.8**。可為每場決鬥和戰役選擇原版曲目或作品音樂，本版也修正《活俠傳》1.0.6001.2 的背景影片匯出。

編輯器介面支援繁體中文。操作、格式與 API 文件統一維護最新版簡體中文，避免舊翻譯的選單與參數誤導。

[下載編輯器](https://github.com/mohui666/lom_modkit/releases/latest) · [中國大陸鏡像](https://toolbox.mahui.site/downloads/lom-modkit/v1.6.8/lom-editor.exe) · [更新內容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.8) · [最新文件](docs/cht/README.md) · [README](README.md)

升級後請退出遊戲，在「遊戲與 MOD」重新配置遊戲環境，將 Host 更新至 1.6.8，再重新啟動遊戲。
