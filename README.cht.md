# 活侠传 · LoM Modkit

目前版本為 **1.6.7**。本版改善長章節統計、舞台預覽、套件驗證與 F5 熱重載。遊戲姓名欄缺字時會優先採用遊戲內相近字形，MOD 模式的部分能力可超過 100。

編輯器介面支援繁體中文。操作、格式與 API 文件統一維護最新版簡體中文，避免舊翻譯的選單與參數誤導。

[下載編輯器](https://github.com/mohui666/lom_modkit/releases/latest) · [中國大陸鏡像](https://toolbox.mahui.site/downloads/lom-modkit/v1.6.7/lom-editor.exe) · [更新內容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.7) · [最新文件](docs/cht/README.md) · [README](README.md)

升級後請退出遊戲，在「遊戲與 MOD」重新配置遊戲環境，將 Host 更新至 1.6.7，再重新啟動遊戲。
