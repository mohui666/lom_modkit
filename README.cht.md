# 活侠传 · LoM Modkit

目前版本為 **1.6.5**。遊戲內 F8 工坊可搜尋原版對白、相關劇情與死亡 CG。開發跳轉可一併設定日期與章節或地點。人物移動會保留先前設定的縱向偏移。

編輯器介面支援繁體中文。操作、格式與 API 文件統一維護最新版簡體中文，避免舊翻譯的選單與參數誤導。

[下載編輯器](https://github.com/mohui666/lom_modkit/releases/latest) · [更新內容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.5) · [最新文件](docs/cht/README.md) · [README](README.md)

升級後請退出遊戲，在「遊戲與 MOD」重新配置遊戲環境，將 Host 更新至 1.6.5，再重新啟動遊戲。
