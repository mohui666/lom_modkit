# 活侠传 · LoM Modkit

目前版本為 **1.6.11**。支援匯入 GIF 動圖、錄製指定劇情片段，並為自訂與原版人物設定傳記和人際頁縮圖。

編輯器介面支援繁體中文。操作、格式與 API 文件統一維護最新版簡體中文，避免舊翻譯的選單與參數誤導。

[下載編輯器](https://github.com/mohui666/lom_modkit/releases/latest) · [中國大陸鏡像](https://toolbox.mahui.site/downloads/lom-modkit/v1.6.11/lom-editor.exe) · [更新內容](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.11) · [最新文件](docs/cht/README.md) · [README](README.md)

升級後請退出遊戲，在「遊戲與 MOD」重新配置遊戲環境，將 Host 更新至 1.6.11，再重新啟動遊戲。
