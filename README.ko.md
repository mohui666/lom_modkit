# 活侠传 · LoM Modkit

현재 버전은 **1.6.0**입니다. 여러 프로젝트 탭과 재시작 시 복원, 창 사이 단계 복사, 게임 본연의 화면을 사용하는 백그라운드 영상 출력, 미리보기 해상도 선택을 추가했습니다.

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.
