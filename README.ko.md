# 活侠传 · LoM Modkit

현재 버전은 **1.6.6**입니다. 게임 내 F8 도구에서 원작 대사와 관련 이야기, 사망 CG를 검색할 수 있습니다. 날짜와 장 또는 장소를 함께 지정해 이동할 수 있습니다. 캐릭터가 이동할 때 설정한 세로 오프셋이 유지됩니다.

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.

[편집기 다운로드](https://github.com/mohui666/lom_modkit/releases/latest) · [업데이트 내용](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.6) · [최신 문서](docs/ko/README.md) · [README](README.md)

게임을 종료하고 「게임과 MOD」에서 게임 환경을 다시 설정해 Host를 1.6.6으로 업데이트한 뒤 게임을 다시 실행하세요.
