# 活侠传 · LoM Modkit

현재 버전은 **1.6.7**입니다. 긴 장의 통계, 무대 미리 보기, 패키지 검사와 F5 다시 불러오기를 개선했습니다. 게임의 이름에 빠진 글자를 비슷한 글꼴로 표시하며, MOD 모드에서 일부 능력치가 100을 넘을 수 있습니다.

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.

[편집기 다운로드](https://github.com/mohui666/lom_modkit/releases/latest) · [중국 본토 미러](https://toolbox.mahui.site/downloads/lom-modkit/v1.6.7/lom-editor.exe) · [업데이트 내용](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.7) · [최신 문서](docs/ko/README.md) · [README](README.md)

게임을 종료하고 「게임과 MOD」에서 게임 환경을 다시 설정해 Host를 1.6.7으로 업데이트한 뒤 게임을 다시 실행하세요.
