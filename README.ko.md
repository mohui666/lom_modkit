# 活侠传 · LoM Modkit

현재 버전은 **1.6.8**입니다. 결투와 전역마다 원작 곡이나 작품의 음악을 선택할 수 있습니다. 《활협전》 1.0.6001.2의 백그라운드 영상 내보내기 문제도 수정했습니다.

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.
