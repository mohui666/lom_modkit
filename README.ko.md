# 活侠传 · LoM Modkit

현재 버전은 **1.6.2**입니다. 게임 내 F8 도구에서 4개 언어, 원작 이벤트와 앞뒤 임무, 조건 설명, 날짜·챕터 이동을 지원합니다. 결투 전용 배경 28개를 추가하고 소매의 결투 로딩 문제를 수정했으며, 실행 중 계산에 Rust 네이티브 구성 요소를 사용합니다.

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.

[편집기 다운로드](https://github.com/mohui666/lom_modkit/releases/latest) · [업데이트 내용](https://github.com/mohui666/lom_modkit/releases/tag/v1.6.2) · [최신 문서](docs/ko/README.md) · [README](README.md)

업데이트 후 게임을 종료하고 「게임과 MOD」에서 게임 환경을 다시 설정하여 Host를 1.6.2로 갱신하세요. 기존 소재 라이브러리는 추가 추출로 결투 배경 썸네일을 받을 수 있습니다. F8 도구 언어는 게임과 작품의 대사 언어에 영향을 주지 않으며, 날짜·챕터 이동은 이전 스토리 기록을 재현하지 않습니다.
