# 活侠传 · LoM Modkit

현재 버전은 **1.6.11**입니다. GIF 가져오기, 지정한 이야기 구간 녹화, 사용자 정의 및 원작 인물의 전기와 관계 화면 썸네일 설정을 지원합니다.

편집기의 한국어 UI는 계속 지원합니다. 오래된 번역의 메뉴와 매개변수를 혼동하지 않도록 최신 사용법과 API 문서는 중국어 간체 원문으로 통합했습니다.
