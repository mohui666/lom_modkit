# 活侠传剧情编辑器 · lom_modkit

用可视化步骤编写《活侠传》的对白、人物演出、事件和自定义玩法，预览后导出作品包，在自己的游戏中试玩。

**当前版本为 1.4.19，Windows x64 只需一个 exe。**

[下载编辑器 exe](https://github.com/mohui666/lom_modkit/releases/download/v1.4.19/lom-editor.exe) · [附说明文档的压缩包](https://github.com/mohui666/lom_modkit/releases/download/v1.4.19/lom_modkit-v1.4.19_windows_x64.zip) · [本版更新说明](RELEASE_NOTES_v1.4.19.md) · [使用教程](docs/chs/software_usage.md) · [文档目录](docs/README.md)

本版统一错误提示，支持更多原版音效试听、人物动作与气泡同时显示，并新增书页事件图淡入。继续兼容旧工程和旧作品包，保留原章节、素材与源码，无需重建作品。

## 安装与更新

### 第一次使用

1. 下载上方 `lom-editor.exe`，放到自己选择的文件夹。
2. 双击运行；配套组件已内置，首次启动会自动准备。
3. 退出游戏，在编辑器的「游戏与 MOD」中点击「一键定位游戏目录」，确认路径后点击「一键配置游戏」。
4. 打开「素材管理 → 游戏预览素材」，点击「一键提取游戏资产」。完成后即可预览原版立绘、背景、插图和气泡动画。

官方图片从你本机安装的游戏中提取，完整编辑器包自带提取组件。安装过程和常见问题见 [Windows 快速开始](docs/chs/windows_quick_start.md)。

### 从旧版升级到 1.4.19

1. 下载新版 `lom-editor.exe`，或通过编辑器内置更新升级，再打开已有作品。图片、动画、原版剧情和音频提取已迁移为 Rust。
2. 提取器、原生音频解码器和同版 Host 已嵌入 exe，首次运行自动准备到 `%LOCALAPPDATA%/lom_modkit/components`；不必再复制配套文件夹。
3. 退出游戏后启动新版编辑器，已安装的 Host 会自动同步。进入「游戏与 MOD」核对三个版本均为 1.4.19，必要时点击「更新游戏 Host」。
4. 给原版人物追加图片时使用「素材管理 → 作品素材 → 为原版人物添加立绘…」。预览缓存中的图片与路径不能用来注册游戏表情。

Windows 用户内容库默认位于 `%APPDATA%\lom_modkit\repository`，设置位于 `%APPDATA%\lom_modkit\rust`。作品及其素材保存在作者选择的项目目录中。新导出的人物素材与自由缩放等功能会自动声明对应最低 Host 版本；已发布作品继续沿用原存档身份。

## 做第一段剧情

1. 在「文件 → 新建项目」中新建「原版附加剧情」或「自由剧本」。附加剧情接入原版流程，自由剧本拥有自己的开场和独立存档。
2. 添加背景、人物登场和对白步骤，在中间填写内容，右侧查看预览。需要角色台词时选择人物和表情，需要旁白时选择旁白模式。
3. 在「剧情安排」设置事件何时触发。整部作品的名称、作者和版本在「作品设置」中填写。
4. 保存项目，按 `F6` 检查章节，再到「发布 → 发布体检与打包」检查整部作品。错误提示中的修改按钮可定位到对应内容。
5. 点击「导出 Mod」生成 `.lommod`，或点击「导出游玩包」生成含自有素材和安装组件的 ZIP，玩家解压后双击「安装MOD.cmd」。右侧「播放」演示编辑器预览，顶栏「试玩」或 `F5` 将作品送入游戏中验证。

第一次创作可按 [核心功能教程](docs/chs/core_tutorial.md) 跟做。随时按 `F1` 打开帮助，步骤标题旁的「说明」可直接查看对应操作。

## 能做什么

| 功能 | 用法 |
| --- | --- |
| 剧情演出 | 共 67 类步骤，覆盖人物、对白、背景、音乐、选项、骰子、决斗和战役等 |
| 原版剧情编辑 | 从本机游戏导入原版章节，修改对白、演出和数值，插入条件剧情，导出后在原触发点执行 |
| 原版路线图 | 「文件 → 原版剧情 → 原版路线图…」查看主支线，游戏中按 `Ctrl+F6` 标记，再用「打开最近游戏标记」定位 |
| 系统提示 | 属性、物品、好感、奖励等步骤可独立开关自动系统提示 |
| 预览布局调整 | 勾选「调整画面」后拖动人物或自定义插图、拉四角等比缩放，支持复位、取消、撤销／重做和保存 |
| 特效演出 | 本机游戏生成的原版动画帧与拖动；画面百分比或世界坐标、横纵缩放／翻转、旋转、速度、定时停止、叠加、标记和重播 |
| 表情气泡 | 支持单句气泡及自动恢复，也可独立编排动画、偏移和拖动定位 |
| 章节与备注 | 章节按组折叠，步骤小字优先备注，空时显示节点编号 |
| 原版人物补绘 | 保留原版人物 ID 和姓名，追加 `tired`、`sleep` 等表情或替换同名立绘，可直接选择预览并随作品导出 |
| 自由缩放 | 人物、CG、叠加图片和介绍卡图片支持游戏可表示的任意正数百分比及小数，取消原先的固定缩放上限 |
| 分辨率适配 | 编辑器按窗口大小自动调整界面并保留系统 DPI，也可手动设置界面缩放；人物按完整站位矩形等比适配 |
| 书页事件图 | 选择原版事件插图或导入自定义图片，等比适配左页，可修改右侧题字和下方文本 |
| 素材检索 | 用分类、缩略图和中文关键词查找图片，搜索“鹤舞”可定位相关剧情插图 |
| 自定义内容 | 导入人物、图片和音频，编辑物品、功法、消耗品、决斗援助与招式动画 |
| 事件和任务 | 编排时间、地点、条件、重复事件、跨事件任务和结算 |
| 长篇创作 | 多章节、分组、复制粘贴、撤销重做、查找引用、流程图和自动恢复 |
| 检查与交付 | 中文错误说明、修改定位、离线测试、发布体检和包检查 |
| 完整游玩包 | 一键导出作品、自有素材、Host、x86/x64 加载组件和安装入口；玩家无需安装编辑器 |
| 多语言 | 编辑器界面和作品译文支持简体中文、繁體中文、日本語、한국어 |

70 类是全工具的步骤总数，各创作模式提供适用的步骤。功能说明与已验证范围见 [当前能力与边界](docs/chs/current_capabilities.md)。

## 常见问题

### 提示缺少素材提取组件

下载新版 `lom-editor.exe` 后直接运行即可。配套组件自动释放到系统缓存，缺失时自动补齐；已有作品无需重建。

### 找不到原版图片或气泡预览

先在「素材管理 → 游戏预览素材」重新提取。场景背景在背景步骤中选择，剧情插图在「图片/标题显示」中按大图、图片或「事件图（书页）」选择。预览素材库用于本机编辑，游戏演出时读取自己的游戏资源。

### 新增表情能预览，却提示人物没有这个表情

不要把补绘图片加到 `game-previews` 或手动改 `preview_map.json`。在「作品素材」使用「为原版人物添加立绘…」，导入后在「指定表情」中选择或追加图片，再在演出步骤中选择同一原版人物与新增表情。图片和表情定义会一起导出，玩家无需你的本地素材库。[具体步骤](docs/chs/user_content.md#为原版人物增加表情)

### 怎样把作品和美术素材一起发给玩家

点击顶栏「导出游玩包」或「文件 → 导出完整游玩包…」。首次导出会下载缺少的加载组件并缓存；玩家收到 ZIP 后完整解压，双击「安装MOD.cmd」即可离线安装，仍需本机已安装正版游戏。游玩包不包含游戏本体或原版预览图片。

### 导出提示存档身份未填写

点击提示中的「去填写存档身份」，编辑器会展开对应设置并定位输入框。存档身份使用小写英文字母、数字、下划线或短横线，长度为一至六十四个字符。已发布作品沿用原编号，以便关联玩家已有存档。

## 平台与验证范围

本版发布 Windows x64 完整包。实机已覆盖原版章节独立入口、选择分支与局部变量汇合、人物清除、动态目标捕获，以及旧格式样例的资源、数据隔离与热重载恢复。完整原版分支和第三方模组组合需按作品实际测试。[当前能力与验证范围](docs/chs/current_capabilities.md)

macOS 可从源码构建，支持编辑、预览和导出，游戏安装与试玩入口在 Windows 上提供。本版 macOS 桌面操作尚未实测。[Mac 编辑器](docs/chs/macos.md)

## 从源码运行

安装 Rust 后，在仓库根目录运行。

```sh
cargo run --locked -p lom-editor
cargo run --locked -p lom-editor -- samples/showcase3
```

核心库、命令行和编辑器分别位于 `rust/lom-core`、`rust/lomc`、`rust/lom-editor`，游戏接入组件位于 `runtime/MortalModHost`。Windows 构建入口为 `scripts/build-windows.ps1`，macOS 为 `scripts/build-macos.sh`。构建、测试及发布附件约定见 [维护者手册](docs/chs/maintainers.md)。

修改游戏功能前请阅读 [仓库规则](AGENTS.md) 和 [接口核对流程](docs/chs/decompiled_api.md)。完整开发文档见 [文档目录](docs/README.md)。
