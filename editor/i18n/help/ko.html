활협전 Mod 시나리오 편집기

처음에는 이것만 기억하세요. 왼쪽에서 단계를 놓고, 가운데에서 고치고, 오른쪽에서 보고, 마지막으로 점검한 뒤 내보냅니다.

5분 만에 첫 장면

  1. 도구 모음 「새로 만들기」. 인물 등장, 보기 대사, 「시나리오 종료」가 준비됩니다.
  2. 왼쪽에서 「대사」를 고르고, 가운데에서 인물·표정·글을 고칩니다.
  3. 「단계 추가」로 등장, 배경, 선택지, 주사위를 더합니다.
  4. 일반 단계는 위에서 아래로 재생됩니다.
  5. 「점검」에 통과하면 「Mod 내보내기」로 .lommod 을 만듭니다.

자주 쓰는 단계

  • 대사：대화, 속마음, 나레이션, 중앙 나레이션.
  • 인물 등장／퇴장：스탠딩과 위치. 먼저 등장시킨 뒤 말하세요. 없으면 검은 화면이 됩니다.
  • 배경 전환：연출 배경을 바꿉니다.
  • 선택지 분기：각 선택지의 다음 단계를 지정합니다.
  • 주사위 판정：공식 검사점을 고르고 성공／실패의 다음을 붙입니다.
  • 시나리오 종료：자유 모드로 돌아가거나 같은 Mod 의 다른 장으로 잇습니다.
  • 한청서 엔딩：원판과 같은 한청서 패널을 내고, 확인 후 타이틀로 돌아갑니다.
  • 사망 화면：짧은 제목, 본문, 900000 이상 전용 번호.

시연

왼쪽에서 단계를 고르고 F5. 점검 뒤 임시 Mod 를 넣고 게임을 켭니다. 정식 내보내기는 덮어쓰지 않습니다.

언어

메뉴 「언어」에서 간체, 번체, 일본어, 한국어를 바꿉니다. 게임 안 고유 명사는 LoM-wiki 를 우선하고, wiki 에 없는 항목（한국어 전문 등）은 게임 공식 언어표에서 가져옵니다.

공식 게임 UI 는 번체 중국어, 간체 중국어, 한국어뿐이며 일본어는 없습니다. 일본어 인명과 능력치 이름은 wiki 일본어 페이지를 따릅니다.

내보내기와 설치

「파일 → 설치 관리」에서 Mortal.exe 가 있는 폴더를 고르고 BepInEx 를 넣으면 내보낸 Mod 를 자동 설치합니다. 게임 안에서는 F8 로 Mod 메뉴입니다.

사용자 콘텐츠 라이브러리

도구 모음의 ‘사용자 콘텐츠’에서 오디오, 사용자 캐릭터와 이미지를 한곳에서 관리합니다. 먼저 콘텐츠 유형을 선택한 뒤 그 유형에 필요한 항목만 입력합니다. 미리 듣기는 오디오 항목에서만 나타납니다. 스토리에는 안정적인 user: ID만 저장하며 PC 절대 경로는 저장하지 않습니다.

분기와 판정

선택지, 조건, 주사위와 각종 판정은 모든 결과에 실제 노드를 지정해야 합니다. 이동은 미리보기 글자만이 아니라 전체 실행 경로를 바꿉니다. F6는 끊어진 링크, 출구 없는 순환과 도달 불가 노드를 검사합니다.

결투와 전역

‘결투(1 대 1)’는 원작 Combat 캐릭터/장면 템플릿을 고르고 상대의 체력, 기력, 능력치, 재능, 필살기와 행동 확률을 설정합니다. ‘원작 대규모 전역’은 Battle 지도를 고르고 아군·적군·중립 편성, 인원, NPC 체력과 플레이어 전역 스킬을 설정합니다. 두 유형은 필드를 섞지 않으며 별도 전투 엔진을 만들지 않습니다.

MOD 전역 저장

타이틀의 ‘MOD 전역 시작’은 원작 불러오기 슬롯 모양을 재사용한 전역 화면을 엽니다. 기존 분리 저장은 바로 이어서 하고, ‘새 전역’ 빈 슬롯에서 아직 저장이 없는 사용자 전역을 고릅니다. 수동 저장, 세 종류 자동 저장과 영속 변수는 MOD별로 분리되며 원작 001～020, 공식 자동 저장이나 Universe 최근 슬롯을 덮어쓰지 않습니다. Mod Quest도 활성 MOD별로 격리하지만 현재는 세션 상태이므로 재시작 후에는 남지 않습니다.

소프트웨어 문서와 스크립트 문서

‘도움말 → 문서’는 독립 창입니다. ‘소프트웨어 사용 문서’는 편집기 조작, 시연, 내보내기와 설치를 설명하고, ‘스크립트 / API 문서’는 실제 노드 Schema에서 각 노드의 모든 매개변수가 무엇을 바꾸는지, 기본값, 최소 JSON 예제와 검증된 런타임 API를 생성합니다.

사용자 제작 콘텐츠 표시

MOD 재생 중에는 전체 출처 정보와 화면 출처 캐리어를 유지합니다. 대사 상자에는 본문과 간격을 두고 아래 중앙에 반투명 한 줄 표시를 둡니다. 사망, 엔딩, 인물 소개 카드에도 로컬 표시가 있습니다. 필수 표시를 유지할 수 없으면 Host가 MOD를 중지하고 안전 장면으로 돌아갑니다.
