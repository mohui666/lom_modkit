활협전 Mod 시나리오 편집기

처음에는 이것만 기억하세요. 왼쪽에서 단계를 놓고, 가운데에서 고치고, 오른쪽에서 보고, 마지막으로 점검한 뒤 내보냅니다.

5분 만에 첫 장면

  1. 도구 모음 「새로 만들기」. 인물 등장, 보기 대사, 「시나리오 종료」가 준비됩니다.
  2. 왼쪽에서 「대사」를 고르고, 가운데에서 인물·표정·글을 고칩니다.
  3. 「단계 추가」로 등장, 배경, 선택지, 주사위를 더합니다.
  4. 일반 단계는 위에서 아래로 재생됩니다.
  5. 「점검」에 통과하면 「Mod 내보내기」로 .lommod 을 만듭니다.

자주 쓰는 단계

  • 대사：대화, 속마음, 나레이션, 중앙 나레이션.
  • 인물 등장／퇴장：스탠딩과 위치. 먼저 등장시킨 뒤 말하세요. 없으면 검은 화면이 됩니다.
  • 배경 전환：연출 배경을 바꿉니다.
  • 선택지 분기：각 선택지의 다음 단계를 지정합니다.
  • 주사위 판정：공식 검사점을 고르고 성공／실패의 다음을 붙입니다.
  • 시나리오 종료：자유 모드로 돌아가거나 같은 Mod 의 다른 장으로 잇습니다.
  • 한청서 엔딩：원판과 같은 한청서 패널을 내고, 확인 후 타이틀로 돌아갑니다.
  • 사망 화면：짧은 제목, 본문, 900000 이상 전용 번호.

시연

왼쪽에서 단계를 고르고 F5. 점검 뒤 임시 Mod 를 넣고 게임을 켭니다. 정식 내보내기는 덮어쓰지 않습니다.

언어

메뉴 「언어」에서 간체, 번체, 일본어, 한국어를 바꿉니다. 게임 안 고유 명사는 LoM-wiki 를 우선하고, wiki 에 없는 항목（한국어 전문 등）은 게임 공식 언어표에서 가져옵니다.

공식 게임 UI 는 번체 중국어, 간체 중국어, 한국어뿐이며 일본어는 없습니다. 일본어 인명과 능력치 이름은 wiki 일본어 페이지를 따릅니다.

내보내기와 설치

「파일 → 설치 관리」에서 Mortal.exe 가 있는 폴더를 고르고 BepInEx 를 넣으면 내보낸 Mod 를 자동 설치합니다. 게임 안에서는 F8 로 Mod 메뉴입니다.
