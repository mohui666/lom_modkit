活俠傳 Mod 劇情編輯器使用指南

第一次使用，只要記住一件事：左邊排步驟，中間改內容，右邊看效果，最後檢查並匯出。

五分鐘做出第一段劇情

  1. 點工具列的「新增」。編輯器會準備一個人物登場、一條示例對白和一個「結束劇情」。
  2. 在左側選擇「對白」，到中間修改人物、表情和文本。
  3. 點「新增步驟」，繼續加入人物登場、場景、選項或骰子。
  4. 普通步驟會按清單從上往下播放。
  5. 點「體檢」。沒有錯誤後，點「匯出 Mod」產生 .lommod 檔。

最常用的步驟

  • 對白：人物說話、內心獨白、旁白和置中旁白。
  • 人物登場／退場：控制立繪與站位。人物必須先登場再說話，否則遊戲會因「角色不存在」而黑屏。
  • 切換背景：更換劇情演出的背景畫面。
  • 選項分支：每個選項都要指定接下來跳到哪個步驟。
  • 骰子檢定：先選官方檢查點，再給成功和失敗結果指定去向。
  • 結束劇情：回到自由模式；也可以接到同一 Mod 的另一個章節。
  • 汗青書結局：顯示與原版相同的汗青書結局面板，確認後回標題畫面。
  • 死亡畫面：填寫短標題、死亡正文和 900000 以上的專用編號。

試玩

先在左側選中要測試的步驟，然後按 F5。編輯器會自動體檢、產生獨立暫存 Mod 並啟動遊戲，不會覆蓋正式匯出的 Mod。

語言

選單「語言」可切換簡體中文、繁體中文、日語、韓語。遊戲內名詞優先採用 LoM-wiki；wiki 沒有的條目取自遊戲解包官方語言表。

官方遊戲介面只有繁中、簡中、韓語，沒有日語。日語人物名與屬性名來自 wiki 日文頁。

匯出與安裝

「檔案 → 安裝管理」選擇含 Mortal.exe 的遊戲資料夾，安裝 BepInEx 後即可自動安裝匯出的 Mod。遊戲內按 F8 開啟 Mod 選單。

使用者內容庫

工具列「使用者內容」統一管理音訊、自訂角色與圖片。先選內容類型，再填寫該類型的欄位；只有音訊項目顯示試聽控制。劇情保存穩定的 user: 編號，不保存電腦絕對路徑。

分支與檢定

選項、條件、骰子與各類檢定必須為每個結果指定真實節點。跳轉會改變完整執行路線，不只是預覽文字；F6 會檢查斷路、死循環與無法到達的節點。

決鬥與戰役

「決鬥（一對一）」選擇原版 Combat 角色／場景範本，可設定對手血量、氣力、屬性、天賦、絕招與行動機率。「原版大規模戰役」選擇 Battle 地圖，可分別設定敵我中立陣容、人數、NPC 血量與玩家戰役技能。兩者不會混用欄位，也不會建立自製戰鬥引擎。

MOD 戰役存檔

標題頁點擊「開始 MOD 戰役」會開啟重用原版讀檔槽視覺的戰役頁。既有隔離存檔可直接繼續；「新戰役」空槽用於選擇尚未建立存檔的自訂戰役。手動檔、三類自動檔與持久變數按 MOD 隔離，不會覆蓋原版 001～020、官方自動檔或 Universe 最近槽。Mod Quest 也按活動 MOD 隔離，但目前只是工作階段狀態，不會跨重啟保存。

軟體文件與腳本文件

「說明 → 文件」是獨立視窗。「軟體使用文件」說明編輯器操作、試玩、匯出與安裝；「腳本 / API 文件」由真實節點 Schema 產生，逐項說明每個節點、每個參數會改變什麼、預設值、最小 JSON 範例與已驗證執行階段介面。

玩家製作內容標識

MOD 演出保留全域來源資訊與畫面來源載體；對白框內另有底部置中的半透明單行標識，並與正文保留間距。死亡、結局與人物介紹卡也有局部標識。必要標識無法維持時，Host 會停止 MOD 並返回安全場景。
