做出第一段劇情

先做一段能從頭播到尾的短故事，再加入人物與背景。左邊排步驟，中間填內容，右邊看效果；「節點」就是劇情中的一步。

從一句對白開始

  1. 檔案 → 新建專案。專案已有示例對白和結束劇情。
  2. 選取對白，在中間修改文字；先用旁白即可開始。
  3. 點右側「開頭」，再點「播放」。手動選取其他步驟會停止播放。
  4. 按 F6 檢查目前章節，依提示回到問題位置修改。
  5. 用 ⌘S（Windows/Linux：Ctrl+S）儲存，完成後從頂欄匯出 .lommod 作品包。
點步驟標題旁的「說明」可直接查看該步驟的幫助；頂欄幫助或 F1 隨時可開啟文件。

人物登場與對白

人物登場負責放入立繪，對白負責顯示台詞。先登場，再移動或退場。

切換背景 → 人物登場 → 對白 → 人物退場 → 結束劇情
  1. 從「＋ 新增步驟」的演出分類加入背景與人物。
  2. 選擇人物、表情、站位。直接就位時，淡入與移動時間都設為 0。
  3. 加入對白，選同一人物並填台詞；環境描述可用旁白。
沒有立繪時，先確認已載入預覽素材。詳見「讓預覽顯示素材」。

讓多個動作同時發生

一般步驟依序執行；同時執行群組內的動作一起開始，全部完成後才繼續下一步。

例子：兩人一起退場

  1. 先讓兩人登場，再加入同時執行群組。
  2. 新增兩個人物退場動作，各選不同人物。
  3. 兩個時間都填 0.5 秒，後續對白放在群組外。
同時執行群組
  人物甲退場：0.5 秒
  人物乙退場：0.5 秒
↓ 全部結束
後續對白
每組 2～32 個演出動作，不能重複控制同一人物或畫面通道。對白、選項、戰鬥與跳轉放在組外。音樂、音效和循環特效啟動後即視為完成，可加等待控制停留。

換景後人物已經就位

先用黑幕蓋住畫面，在幕後換景並安排人物，最後揭幕。

  1. 轉場選淡入，蓋上黑幕。
  2. 切換到新背景。
  3. 安排人物登場，淡入與移動時間都設 0；多人可放進同時執行群組。
  4. 轉場選淡出，揭開黑幕。
淡入蓋幕 → 換背景、人物就位 → 淡出揭幕 → 對白
這裡的淡入與淡出指黑幕的出現和消失。編輯器轉場節奏為示意，實際時間由遊戲決定。

讓預覽顯示素材

快捷入口：檔案 → 從遊戲提取預覽素材…。選擇含 Mortal_Data 的遊戲安裝目錄，完成後自動載入。已有素材庫則選含 preview_map.json 和 assets 的完整資料夾，一般圖片資料夾不能直接載入。選素材庫時若選中遊戲目錄，也會自動提取。

重要人物依「人物 → 外觀 → 表情」選擇，例如「虞小梅 → 入魔」。只列出該外觀可用的表情；切換外觀時，不可用的舊表情會恢復為正常表情。場中換用另一官方人物設定時，先讓舊外觀退場，再讓新外觀登場。

遊戲預覽素材留在本機供編輯器顯示；自製素材由使用者內容加入作品。

提取遊戲圖片

  1. 打開頂欄「素材管理 → 遊戲預覽素材」。
  2. 在遊戲預覽素材區點一鍵提取遊戲資產。
  3. 選自己的遊戲目錄，完成後自動載入立繪、表情與背景。

已有素材庫可從檔案選單載入。遊戲預覽圖片不會自動加入匯出的作品。

匯入自製素材

素材管理 → 作品素材 → 匯入素材，再到步驟表單選取。圖片沒出現時，確認素材庫、人物及表情後，從開頭重播。

選項、跳轉與結束

未指定跳轉時按左側順序播放。選項或條件分支可指定不同後續步驟。

  1. 先準備選項後要播放的對白。
  2. 加入選項分支，填文字並為每項選擇後續步驟。
  3. 按 F7 看流程圖，再逐條預覽。

結束劇情怎麼填

  • 下一章節留空：結束目前章節，回自由模式。
  • 選擇下一章節：結束後接著播放該章。
獨立故事：對白 → 結束劇情（下一章節留空）
接續故事：對白 → 結束劇情（選下一章節）
旗標是事件記錄，例如已見過師兄。條件分支可依這個記錄決定下一段。

看懂檢查與操作結果

先看結果視窗頂部結論，再依問題位置修改。原始資料收在技術詳情。

  • 狀態正常：此次檢查未發現問題。
  • 需要修正：依提示補填或修正劇情。
  • 待遊戲確認：離線不能確認，尚未通過。

F6 檢查目前章節。完整檢查：發佈 → 發布檢查與打包 → 發布檢查。

耗時任務可收起繼續編輯，從底部重新開啟進度或結果；完成後會提示。

編輯器預覽與遊戲試玩

右側播放只在編輯器顯示台詞、位置、同時動作與黑幕換景，不會啟動遊戲。

  • 開頭回章節起點；暫停後可繼續。
  • 手動選取其他步驟會停止播放。
  • F7 顯示流程圖。

Windows 的試玩或 F5 會檢查作品、產生獨立臨時包並啟動遊戲。遊戲目錄、自動設定與 MOD 清單在頂欄「遊戲與 MOD」頁面管理；Mac 不提供遊戲試玩。

轉場時間為示意；音訊、濾鏡、戰鬥及其他遊戲系統仍需在遊戲確認。

常用詞，簡單說

使用表單創作不需要先學程式。

  • 節點：劇情的一步。
  • 旗標：記住某件事是否發生。
  • 條件分支：依記錄或數值決定去向。
  • 預覽素材庫：本機顯示立繪與背景的圖片集合。
  • 作品包：匯出的 .lommod 檔案。
  • 宿主：讓遊戲載入作品的接入元件。
  • API：寫程式時使用的功能介面。
  • Lua：編輯器依步驟產生的程式，通常不需手寫。

儲存、語言與快捷鍵

Mac 從應用程式選單的設定或 ⌘, 開啟設定；Windows/Linux 使用設定或 Ctrl+,。作品台詞翻譯在編輯選單的多語言。

  • ⌘S / Ctrl+S：儲存。
  • F1：幫助。
  • F6：檢查目前章節。
  • F7：流程圖。
  • F5：Windows 遊戲試玩。
  • Esc：關閉幫助或提示視窗。
