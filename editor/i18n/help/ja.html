最初の物語を作る

まず短い物語を完成させてから、人物や背景を追加しましょう。左で手順を並べ、中央で編集し、右で確認します。ノードは物語の一つのステップです。

一つの会話から始める

  1. ファイルから新規プロジェクトを作成。会話の例とシナリオ終了が入っています。
  2. 会話を選び、中央で文章を編集。最初はナレーションだけで構いません。
  3. 右側の先頭、再生を押します。別のステップを選ぶと再生が止まります。
  4. F6 で現在の章を検査し、問題の場所に戻って修正します。
  5. ⌘S（Windows/Linux：Ctrl+S）で保存。完成したら Mod 書き出しで .lommod を生成します。
各ステップの見出し横の説明ボタンから、そのステップのヘルプを直接開けます。上部のヘルプまたは F1 でいつでも戻れます。

人物の登場と会話

登場は立ち絵を配置し、会話は台詞を表示します。登場してから移動や退場を設定します。

背景変更 → 人物登場 → 会話 → 人物退場 → 終了
  1. ステップ追加の演出から背景と人物を加えます。
  2. 人物、表情、位置を選択。すぐに配置する場合はフェードと移動時間を両方 0 にします。
  3. 会話で同じ人物を選び、台詞を入力。情景描写にはナレーションを使います。
立ち絵が見えない場合は素材庫を読み込んでください。素材の項目で手順を確認できます。

複数の動作を同時に実行

通常のステップは順番に進みます。同時実行グループはすべて一緒に始まり、全動作が終わってから次へ進みます。

例：二人が同時に退場

  1. 二人を登場させ、同時実行グループを追加。
  2. 人物退場を二つ加え、別々の人物を選択。
  3. 両方を 0.5 秒に設定。続く会話はグループの外に置きます。
同時実行グループ
  人物 A 退場：0.5 秒
  人物 B 退場：0.5 秒
↓ 全動作が完了
次の会話
一組 2～32 動作。同一人物や画面チャンネルは重複操作できません。会話、選択肢、戦闘、ジャンプは外に配置。音楽・効果音・ループ効果は開始時に完了扱いのため、必要なら待機を加えます。

場面を開く前に人物を配置

暗幕を掛け、その裏で背景と人物を準備し、最後に暗幕を開きます。

  1. トランジションのインで暗幕を掛ける。
  2. 背景を変更する。
  3. 人物を登場させ、フェードと移動時間を 0 にする。複数なら同時実行グループを使う。
  4. トランジションのアウトで暗幕を開く。
暗幕を掛ける → 背景変更・人物配置 → 暗幕を開く → 会話
イン／アウトは暗幕の出現／消失です。エディターの時間は確認用の目安で、実際の時間はゲーム側で決まります。

プレビューに素材を表示

ファイル → ゲームからプレビュー素材を抽出…から、Mortal_Data を含むゲームフォルダーを選択すると、抽出後に自動で読み込みます。既存の素材集は preview_map.json と assets を含むフォルダー全体を選択します。通常の画像フォルダーは直接読み込めません。

主要人物は「人物 → 外観 → 表情」の順に選びます。外観ごとに使用可能な表情のみ表示します。外観変更後に使えない表情は通常表情に戻ります。別の公式人物設定へ切り替える場合は、古い外観を退場させてから新しい外観を登場させます。

ゲームのプレビュー素材はこの端末に保存します。自作素材はユーザーコンテンツから作品に追加します。

ゲーム画像を抽出する

  1. 上部の素材管理からゲームプレビュー素材を開く。
  2. ゲームプレビュー素材で一括抽出を選ぶ。
  3. 自分のゲームフォルダーを指定。立ち絵、表情、背景を抽出して自動で読み込みます。

既存の素材庫はファイルメニューから選択。プレビュー画像は作品に自動では含まれません。

自作素材を取り込む

素材管理の作品の素材から素材インポートで追加し、ステップのフォームで選びます。見えないときは素材庫と人物・表情を確認して先頭から再生してください。

選択肢、ジャンプ、終了

ジャンプがなければ左側の順序で再生します。選択肢や条件分岐で行き先を変えられます。

  1. 選択後に表示する会話を先に用意。
  2. 選択肢分岐を追加し、文章と行き先を設定。
  3. F7 で経路を確認してから各ルートを再生。

シナリオ終了の設定

  • 次の章が空欄：章を終えて自由モードへ戻る。
  • 次の章を指定：終了後にその章を再生する。
独立した話：会話 → 終了（次の章は空欄）
続きのある話：会話 → 終了（次の章を選択）
フラグは「人物に会った」などの記録。条件分岐でその記録を確認できます。

検査結果の読み方

結果ウィンドウの結論を先に読み、問題の場所へ戻って修正します。元のデータは技術詳細にあります。

  • 正常：今回の検査では問題なし。
  • 修正が必要：表示された項目を修正。
  • ゲーム内確認待ち：オフラインでは判断できず、まだ合格ではない。

F6 は現在の章。全体の検査は公開ページの公開検査・梱包から行います。

長い処理は畳んで編集を続けられます。下部から進捗や結果を再表示でき、完了時にも通知します。

プレビューとゲーム試遊

右側の再生はエディター内で台詞、位置、同時動作、暗幕を確認する機能です。ゲームは起動しません。

  • 先頭で章の最初へ戻る。一時停止後は続行可能。
  • 別のステップを選ぶと停止。
  • F7 でフローチャート。

Windows の試遊または F5 は検査後に独立した一時パッケージを作りゲームを起動します。ゲームの設定と MOD 一覧は上部の「ゲームと MOD」にあります。Mac はゲーム試遊非対応です。

転換時間は目安です。音声、フィルター、戦闘などの実際の効果はゲーム内で確認してください。

用語をやさしく説明

フォームでの制作にプログラミング知識は不要です。

  • ノード：物語の一つのステップ。
  • フラグ：出来事が起きたかを記録。
  • 条件分岐：記録や数値で行き先を選ぶ。
  • 素材庫：この端末で表示する画像集。
  • 作品パッケージ：書き出した .lommod ファイル。
  • ホスト：ゲームに作品を読み込ませる接続部品。
  • API：プログラムから使う機能の入口。
  • Lua：エディターが手順から生成するコード。通常は手書き不要。

保存、言語、ショートカット

Mac はアプリメニューの設定か ⌘,、Windows/Linux は設定か Ctrl+, で表示言語を変更します。物語の翻訳は編集メニューの多言語から行います。

  • ⌘S / Ctrl+S：保存。
  • F1：ヘルプ。
  • F6：現在の章を検査。
  • F7：フローチャート。
  • F5：Windows ゲーム試遊。
  • Esc：ヘルプやダイアログを閉じる。
