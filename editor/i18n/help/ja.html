活俠傳 Mod シナリオエディタ

初めて使うときはこれだけ覚えてください。左で手順を並べ、中央で内容を直し、右で確認し、最後に検査して書き出します。

5 分で最初の一節

  1. ツールバーの「新規」。人物登場、見本の台詞、「シナリオ終了」が用意されます。
  2. 左で「台詞」を選び、中央で人物・表情・本文を直します。
  3. 「手順を追加」で登場、背景、選択肢、ダイスを足します。
  4. ふつうの手順は上から下へ再生されます。
  5. 「検査」に通ったら「Mod を書き出す」で .lommod を作ります。

よく使う手順

  • 台詞：会話、内心独白、旁白、中央旁白。
  • 人物登場／退場：立ち絵と位置。先に登場させてから話してください。いないと黒画面になります。
  • 背景切替：演出背景を変えます。
  • 選択肢分岐：各選択肢の次の手順を指定します。
  • ダイス判定：公式の検査点を選び、成功／失敗の行き先を付けます。
  • シナリオ終了：フリーモードへ戻るか、同じ Mod の別の章へつなぎます。
  • 汗青書エンディング：公式と同じ汗青書パネルを出し、確認後にタイトルへ戻ります。
  • 死亡画面：短い題、本文、900000 以上の専用番号。

試遊

左で手順を選び F5。検査のあと一時 Mod を入れてゲームを起動します。正式書き出しは上書きしません。

言語

メニュー「言語」で簡体・繁体・日本語・韓国語を切り替えます。ゲーム内の固有名詞は LoM-wiki を優先し、wiki に無い項目（韓国語全文など）はゲームの公式言語表から取ります。

公式ゲームの UI は繁体中国語・簡体中国語・韓国語のみで、日本語はありません。日本語の人名とステータス名は wiki 日本語ページに従います。

書き出しと導入

「ファイル → インストール管理」で Mortal.exe のあるフォルダを選び、BepInEx を入れると書き出した Mod を自動導入できます。ゲーム内は F8 で Mod メニューです。

ユーザーコンテンツライブラリ

ツールバーの「ユーザーコンテンツ」で音声、カスタムキャラクター、画像を一元管理します。最初に種類を選び、その種類に必要な項目だけを入力します。試聴操作は音声項目だけに表示されます。シナリオには安定した user: ID を保存し、PC の絶対パスは保存しません。

分岐と判定

選択肢、条件、ダイス、各種判定では、すべての結果に実在するノードを指定します。遷移はプレビュー文字だけでなく実行経路全体を変更します。F6 はリンク切れ、出口のないループ、到達不能を検査します。

決闘と戦役

「決闘（1 対 1）」は原作 Combat の人物／シーンテンプレートを選び、相手の体力、気力、能力、才能、奥義、行動確率を設定します。「原作大規模戦役」は Battle マップを選び、味方・敵・中立の編成、人数、NPC 体力、プレイヤー戦役スキルを設定します。両者の項目は混在せず、独自戦闘エンジンも作りません。

MOD キャンペーンセーブ

タイトルの「MOD戦役を開始」は、原作ロード画面のスロット表示を再利用したキャンペーン画面を開きます。既存の分離セーブは直接続行でき、「新規キャンペーン」スロットから未作成のカスタムキャンペーンを選びます。手動、3 種の自動セーブ、永続変数は MOD ごとに分離され、原作 001～020、公式自動セーブ、Universe の最近スロットを上書きしません。Mod Quest も活動 MOD ごとに分離しますが、現在はセッション状態で、再起動後には残りません。

操作ガイドとスクリプトリファレンス

「ヘルプ → ドキュメント」は独立ウィンドウです。「ソフトウェア操作ガイド」は編集、試遊、書き出し、導入を説明し、「スクリプト / API リファレンス」は実際のノード Schema から各ノード、項目、既定値、最小 JSON 例、検証済みランタイム API を生成します。

ユーザー制作コンテンツ表示

MOD 再生中は全体の出所表示と画面キャリアを維持します。台詞枠には本文と間隔を空け、下中央に半透明の 1 行表示を追加します。死亡、結末、人物紹介カードにも局所表示があります。必須表示を維持できない場合、Host は MOD を停止して安全なシーンへ戻します。
