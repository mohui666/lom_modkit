活侠传剧情编辑器 · 使用指南

做出第一段剧情

先写一段能从头播到尾的短剧情，再加背景、人物和选项。左边排步骤，中间填内容，右边看效果；“节点”就是剧情中的一步。

从一句对白开始

  1. 在“文件”中选择“新建自由剧本”或“新建原版附加剧情”。前者从自己的开场开始，后者给原版流程添加事件；两者都有示例对白和“结束剧情”。
  2. 选中左侧“对白”，在中间修改台词。先用旁白就能完成第一段剧情，不必准备人物图片。
  3. 点右侧“开头”，再点“播放”。想修改时先暂停；手动选择其他步骤会停止播放。
  4. 按 F6 查看编译结果，再点“检查项目”。出现问题时，按提示回到对应步骤修改。
  5. 用 ⌘S 保存（Windows/Linux 用 Ctrl+S）。完成后点顶栏“导出 Mod”，生成 .lommod 作品包。
想看某一步怎么填？点击中间标题旁的“说明”，会直接打开该步骤的帮助。顶栏“帮助”或 F1 可随时回到这里。

接下来做什么

在左侧“剧情安排”设置事件的年月旬、地点、重复间隔和可选任务进度；“作品设置”管理整部作品的名称和作者。想给演出加上人物，从帮助目录选择“人物登场与对白”；想做多人同时行动，查看“让多个动作同时发生”。

人物登场与对白

“人物登场”负责把立绘放到画面里，“对白”负责显示台词。先让人物登场，再安排移动或退场，会更容易看懂演出顺序。

一个完整的小例子

↓
人物登场：选择人物、表情和站位
↓
对白：选择同一个人物，写一句台词
↓
人物退场
↓
结束剧情
  1. 点左侧“＋ 添加步骤”，从演出分类加入背景和人物登场。
  2. 在人物登场表单里选择人物、表情、位置。需要直接出现在原位时，把淡入和移动时长都设为 0。
  3. 加入对白，选择说话人物并写台词。要写环境描写或没有人物的文字，使用旁白。
  4. 想让人物走动就加“人物移动”；想让人物离开就加“人物退场”。可以拖动左侧步骤调整先后顺序。
看不到立绘时，先确认是否已经载入预览素材。设置人物编号不会自动把游戏图片复制到编辑器里，具体操作见“让预览显示素材”。

让多个动作同时发生

普通步骤按顺序执行。“同时执行组”把多个演出动作放在同一组里：一起开始，等全部动作结束，再继续后面的步骤。

例子：让两个人一起退场

  1. 先让两个人物登场，再添加“同时执行组”。
  2. 在组内添加两个“人物退场”，分别选择不同的人物。
  3. 两个动作的时长都填 0.5 秒。把需要的对白放在组外、组的后面。
  4. 从组前面的步骤开始播放。两个人会一起淡出，随后才进入对白。
同时执行组
  动作 1：人物甲退场，0.5 秒
  动作 2：人物乙退场，0.5 秒
↓ 两个动作都结束
后续对白

组内放什么

可以放人物登场、移动、退场以及表单提供的其他演出动作。每个组包含 2～32 个动作；对白、选项、战斗和跳转放在组外。

同一组不能同时控制同一个人物，也不能重复占用同一个画面通道。音乐、音效和循环特效在启动后就视为完成；若要停留一会儿，可在组内加入“等待”。

换景后人物已经就位

目标是揭开黑幕后，新背景和人物已经同时在画面中。先遮住画面，在黑幕后换景、放人物，最后揭幕。

按这个顺序排列

  1. 添加“转场”，选择“淡入”：让黑幕盖住画面。
  2. 添加切换背景，在黑幕后换到新场景。
  3. 添加人物登场，把淡入和移动时长都设为 0；多个人物可以放进同一个“同时执行组”。
  4. 再添加“转场”，选择“淡出”：揭开黑幕，让背景和已就位的人物一起显现。
转场：淡入（盖上黑幕）
↓
切换背景 → 人物就位
↓
转场：淡出（揭开黑幕）
↓
对白
这里的“淡入 / 淡出”指黑幕出现和消失。右侧能预览遮挡和揭幕；转场节奏为示意，游戏中的实际时长由游戏决定。

让预览显示素材

快捷入口：文件 → 从游戏提取预览素材…。选择含 Mortal_Data 的游戏安装目录，完成后自动载入。已有素材库则选含 preview_map.json 和 assets 的完整文件夹；普通图片文件夹不能直接载入。选择素材库时若选中游戏安装目录，也会自动开始提取。

重要人物按“人物 → 外观 → 表情”选择，例如“虞小梅 → 入魔 → 特殊表情”。切换外观后只列出它实际可用的表情，不可用的旧表情恢复为正常表情。场中更换为另一官方人物配置时，先让旧外观退场，再让新外观登场。

游戏预览素材用于编辑器右侧的画面。自己的图片、人物和音频则通过“用户内容”加入作品，两者入口不同。

使用游戏里的立绘、表情和背景

  1. 在顶栏打开“素材管理 → 游戏预览素材”。
  2. 找到“游戏预览素材”，点“一键提取游戏资产”。
  3. 选择自己安装的游戏目录。提取过程中可看进度，完成后会自动载入预览。

已有素材库时，从“文件 → 选择预览素材库…”载入即可。提取的游戏图片留在本机，不会自动加入导出的作品包。

使用自己制作的素材

打开“素材管理 → 作品素材 → 导入素材…”，导入自己的图片、人物或音频，再到相应步骤的表单中选择它。

立绘或背景没显示时：确认素材已载入 → 检查步骤中选的人物和表情 → 回到开头重新播放。编辑器预览不代表所有游戏效果都已验证。

选项、跳转与结束

没有跳转时，剧情会按左侧的顺序向下播放。选项和条件分支可以把剧情带到另一处；结束剧情用来为当前章节收尾。

写一个有去向的选项

  1. 先添加选项之后要播放的对白或步骤。
  2. 添加“选项分支”，为每个选项写文字，并选择对应的后续步骤。
  3. 按 F7 看流程图，检查每个选项是否连到了预期的位置；再用右侧播放逐条查看。

“结束剧情”怎么填

  • “下一章节”留空：当前章节结束，回到自由模式。
  • 选择了“下一章节”：当前章节结束后接着播放该章节。
只写一段独立剧情：对白 → 结束剧情（下一章节留空）
继续下一章：对白 → 结束剧情（选择下一章节）
“剧情旗标”就是一条事件记录，例如“已经见过师兄”。设置旗标后，可以用条件分支决定以后该走哪段剧情。

看懂检查与操作结果

检查结果会弹窗显示。先看顶部结论，再看具体问题及位置；原始字段和完整数据收在“技术详情”，需要排查时再展开。

这些结果是什么意思

  • 状态正常：这次检查没有发现问题。
  • 需要修正：有漏填内容或无法继续的剧情，按问题位置返回修改。
  • 待游戏确认：编辑器离线无法确认这一项，需要以后在游戏里验证。

检查入口与进度

F6 检查当前章节。完整作品检查：打开“发布”，在“发布体检与打包”里选择“发布体检”。

耗时任务可以点“收起，继续编辑”。底部“查看进度或结果”能重新打开窗口；完成后还会提示结果。

“状态正常”只对应当前这次检查；“待游戏确认”不会被当作已通过。遇到错误请保留结论和具体问题，方便定位。

编辑器预览与游戏试玩

右侧的“播放”用来边写边看，不会启动游戏。它适合检查台词、立绘位置、同时动作和黑幕换景。

在编辑器里看

  • “开头”回到章节起点，“播放”继续自动演出，“暂停”停下来修改。
  • 手动选择另一条步骤会停止自动播放。
  • F7 切换到流程图，适合检查选项和分支的去向。

在游戏里看

Windows 的“试玩”按钮或 F5 会先检查作品，生成独立的临时试玩包并启动游戏。游戏目录、自动配置和 MOD 列表在顶栏“游戏与 MOD”页面管理；Mac 不提供游戏试玩。

转场预览使用示意节奏；音频、滤镜、战斗以及其他游戏系统效果仍以游戏内表现为准。

常用词，用人话说

用表单写剧情时，不需要先学编程。遇到不熟悉的词，可以先按下面的意思理解。

  • 节点：剧情中的一步，例如一句对白、人物登场或一个选项。
  • 剧情旗标：记住某件事是否发生过的一条记录。
  • 条件分支：先检查记录或数值，再决定后续走向。
  • 预览素材库：保存在本机、供编辑器显示立绘和背景的图片集合。
  • 作品包（.lommod）：导出后交给游戏加载的 MOD 文件。
  • 游戏接入组件（宿主）：让游戏能加载作品的组件，首次安装时准备。
  • 接口（API）：供写代码的人调用的功能入口。表单创作时无需使用。
  • 脚本（Lua）：作品背后执行的代码。编辑器会根据步骤生成，通常不用手写。

保存、语言与快捷键

新建或打开作品后，记得定期保存。编辑器界面语言和作品中的台词翻译是两件事。

切换语言

Mac：屏幕顶部应用菜单的“设置…”或 ⌘,。Windows/Linux：“设置…”或 Ctrl+,。可切换简体中文、繁体中文、日语和韩语。作品台词的翻译在“编辑 → 多语言”里处理。

常用快捷键

  • ⌘S / Ctrl+S：保存作品。
  • F1：打开帮助。
  • F6：检查当前章节。
  • F7：查看流程图。
  • F5：Windows 游戏试玩。
  • Esc：关闭帮助或当前提示窗口。
